# Mower RIIC

先区分机制资料、AI 主班草案和前端收益演算。读取[AI 助手子系统说明](../../../docs/subsystems/ai-assistant.md#riic-tools)或[排班编辑器说明](../../../docs/subsystems/plan-editor.md#income-export)中本次操作对应的输入与边界。

## 机制与 AI

- `arknights_mower/data/riic/knowledge.json` 保存精简机制指南及来源。用 `get_riic_knowledge` 的 topic 获取相关主题；维护时同步工具枚举。完整技能和嵌套术语从 `utils/building_skills.py` 的共享资源读取，不复制另一份 AI 目录。
- `get_riic_context` 读取已同步 BOX、练度和现有设施。用户明确提供的覆盖在每个相关调用中一致传递；未知练度保持未知。每个独立技能槽只用当前已解锁的最高版本。
- 组合名单不是同站名单。先核对提供者、受益者、设施、产品、心情和同一时段条件；档案国籍不能替代技能术语的明确成员。
- `try_riic_plan` 的成功仅说明只读主班检查通过。展示未检查项，不声称已保存、已执行、长期轮换可行或收益最优。收益计算由前端窗口启动，AI 现有工具不执行演算。

## 收益演算维护

读取[维护与验证](references/maintenance.md)。固定引擎保留上游相对目录和来源摘要；适配层负责 Mower 输入、参数、Worker 生命周期及图表。不要为了修补 UI 改写计算公式或压缩掉原排班中的未知字段。

本次图片、演算和报告使用同一个排班快照。开始演算时自动校验该快照，只有校验成功才创建 Worker；全员满练与手动练度跳过森空岛名单检查，缓存模式只检查本地数据，不触发同步。练度与库存默认读取森空岛缓存，未知练度和未报告的基础资源不可补造。收益参数及结果不自动保存到排班配置；用户在窗口切换共享算法则同步保存到 Mower 收益设置。本次自定义权重不写入共享设置。预热不计收益，库存跨阶段连续且没有外源补货；赤金透支是显式模型选项，其他材料仍受库存约束。回收站只计产出次数，不产生材料或材料价值。完成后先展示数据和日志，用户点击导出按钮才生成 JPG，名称及文件名后的收益信息使用本次完成结果；图片顶部显示日均收益、产物小图标和注明演算天数的验证章，不渲染排班名；保留无人机设施标记，赤金显示制造加特殊订单溢价的龙门币等价值，龙门币显示净增减。浏览器只保留最近一次成功演算的结果、参数、日志、原排班及图片；重开或刷新后恢复，新演算失败或停止不覆盖旧记录。导出必须读取保存的原图、主题、设施位置及排班，不能混用当前编辑表。停止或异常不能导出不完整收益。旧 Worker 消息不得覆盖新计算。

## 交付

按修改的真实调用方运行定向离线验证。分别报告机制来源、行为测试、图片往返、构建和实际设备证据；上游固定测试不自动构成本地通过结果。文档或 skills 变化运行项目结构与文本检查。普通局部维护不自动新增决策记录或术语条目。
