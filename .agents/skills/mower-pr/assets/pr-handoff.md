# PR 写作交接

## 范围

- 自然任务请求：〈请求及授权边界〉
- 用户明确的表达要求：〈格式、语言和称呼偏好；提取要求，不附候选标题或草稿〉
- 实际 base/head：〈commit 或明确的工作区范围〉
- 完整最终 diff：〈文件位置〉
- 整体范围陈述：〈被修改的功能或维护对象、它处理或约束的内容、修改前后的具体差异及主次依据〉
- scope 选择：〈已核实的既有英文范围、配置或相关路径历史等来源，以及选择或省略依据；已有标题的 scope 是否仍适用〉
- 写作规则及依赖版本：〈来源位置〉

## 必需事实

整理者从原始材料确认事实、依据和审阅用途；最终复核者回读原始依据后填写正文落点。来源包含未进入 commit 的现场材料与数据修复，缺少依据时写明缺项。

| 已核实事实或具体缺项 | 原始依据与版本 | 审阅用途 | 最终正文落点 |
| :--- | :--- | :--- | :--- |
| 〈事实〉 | 〈来源〉 | 〈问题、方案、证据或恢复判断〉 | 〈栏目与主题〉 |
