# Mower Commit

本 skill 在 Arknights Mower 仓库内使用。输入是用户需求、本次提交的实际 diff 和已有检查记录，输出是中文提交说明及已授权提交的结果。执行范围沿用[项目工作流](../../AGENTS.md#1-task-selection)。

## 1. 确认提交范围

读取工作区状态、工作区 diff 和暂存 diff，按本次任务选择文件或代码片段。已有暂存内容也需核对归属，保留其他修改原有的暂存状态。

确定本次提交的完整 diff 后，核实核心变化、实际对象和前后结果。一次提交围绕一个可独立说明的改动组织；需要拆分时，分别确定每次提交的范围和标题。

## 2. 编写提交说明

读取[共享标题规则](references/title.md)，根据本次提交的完整 diff 和已核实事实生成标题。

标题与 diff 已能说明的事实无需重复。需要解释改动原因、必要取舍或使用条件时，在提交正文中补充，并采用[项目文风规范](../mower-prose-standard/SKILL.md)。验证结论使用已有执行记录，注明影响结论的失败或未验证范围。

## 3. 提交与核对

请求仅编写提交说明时，交付标题和所需正文。请求执行提交时，按已有授权暂存本次改动，读取实际提交所用的完整暂存 diff，再核对标题、正文与提交范围。

按[项目验证要求](../../AGENTS.md#4-verification-and-reporting)完成相关检查并记录实际结果。有多行正文时，将提交说明写入临时文件，通过 `git commit --file` 提交，保留原有换行。

提交完成后，读取生成的提交说明和 diff，确认提交内容符合本次范围，其他修改的暂存状态得到保留。交付实际提交、主要变化和相关检查结果；后续推送或 PR 发布按对应任务的授权执行。
