# 使用显式凭据的日志转发

前端按浏览器来源构造 `/log`，保留公网端口，并在 HTTPS 页面使用 `wss`。代理可以终止 HTTPS，或将 Host 改写为内网地址。浏览器 Origin 与后端地址之间的比较会拒绝凭据正确的日志订阅。

[Web 访问契约](../../../../docs/subsystems/web-access.md) 定义接口与 [INV-WEB-02]。日志路由以首帧显式提交的令牌作为授权边界，不依赖 Origin、Host 或转发头。浏览器不自动附带该凭据。无令牌本机访问保留 [INV-WEB-01]；AI 与诊断修改接口保留原有来源校验。

实现前的简化审查保留共用凭据校验，来源解析器在其他调用路径上保持原有行为。日志路由通过已有的路由专用标志选择仅凭据授权，不引入额外的代理解析器或配置。

## 标准审查结果

改动保留五秒凭据期限、有界日志订阅和无令牌回环访问限制，不改变领域定义、配置结构、设备生命周期或调度机制。

## 规格审查结果

离线回归覆盖有效凭据下的 HTTPS 终止、端口变化、Host 改写、IPv6 和缺少 Origin，拒绝缺失或无效凭据及利用转发头的无令牌访问，保留 AI 与诊断来源校验。回环 WebSocket 测试经过生产 `/log` 路由，以公网 HTTPS Origin 和内网 HTTP Host 验证初始历史及后续日志。前端测试验证公网 WebSocket 地址与重连凭据发送。真实 frp 或路由器部署尚未验证。

基于 alpha 的 PR 检出通过 54 项后端定向测试和 13 项前端测试。Ruff、Prettier 和差异空白检查通过。治理的三项结构检查通过，保留两条既有归档引用兼容警告。标准与规格审查无可操作发现。
