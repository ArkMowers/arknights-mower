# Workshop delayed cloud inventory

成功的云端请求仍可能携带滞后的材料库存，请求开始时间不能覆盖加工站已确认的产出与消耗。持久化待同步基线和变化方向保护受影响物品。仅产出的物品可在云端库存达到或超过预测库存时校准，仅消耗的物品可在云端库存达到或低于预测库存时校准。既产出又消耗的物品，以及迁移后方向未知的记录，只接受与预测库存完全相等的云端读数，或较新且覆盖该物品的实际仓库读数。部分扫描中未出现的物品不视为实际零库存。所有加工干员、手动合成与养成规划共用此数据库。上下限均为绝对库存阈值。回归测试覆盖三块固化纤维板、三个酮阵列、一个异铁块在多次滞后请求下的连续合成。

[INV-STOCK-01] 同时保护先产出后消耗的中间材料：两次操作之间的滞后库存不能覆盖已确认的最终库存。回归测试覆盖双向变化与重启持久化。
