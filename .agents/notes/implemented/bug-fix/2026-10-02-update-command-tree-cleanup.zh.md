# 更新命令进程树清理

## 契约

[INV-UPD-01] 在执行前取得每条 Windows 更新命令及后代进程的所有权。取消、超时和正常完成在有限预算内核验所属进程树退出，再释放临时检出目录。准备阶段取消时，其他应用实例保留进程和文件。

## 简化

仅依赖标准库的安装器为每条命令持有一个 Windows Job，取代 taskkill 的进程树枚举，并共用终止和完成核验。没有新增配置、外部依赖或兼容别名。既有取消和事务断言保持有效。

## 验证

命令进度与源码事务专项覆盖取消、超时、正常完成、后代进程与原实例保留，不执行设备集成。Windows CI 验证原生进程边界。

## 审查

Standards Findings：命令隔离仅使用标准库，保留固定参数列表和有界清理，不操作无关实例。

Spec Findings：五项新增回归覆盖执行前收纳、取消和超时顺序、分配失败、后代退出及清理预算。命令与事务专项通过 112 项及 152 个子测试；两个既有平台跳过保持不变。Ruff 与治理检查通过，原生 Windows 行为由 CI 验证。

代理环境测试同时模拟命令隔离与 Popen，保留环境变量断言，避免将模拟句柄传给原生 Windows API。
