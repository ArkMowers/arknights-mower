# 未配置令牌时的本机日志读取

共用的 WebSocket 凭据校验会拒绝未携带令牌的本机日志订阅。前端在地址中没有令牌时也会跳过连接。这两处行为使该状态下的本机 WebView 无法显示实时日志。

桌面启动器保留运行时凭据和本机监听。未配置 Web UI 令牌时，只读日志请求改用本机地址与浏览器来源边界。AI 聊天、AI 分析和修改类接口继续校验凭据。源码文件读取仍受现有允许列表限制。AI 聊天仍需要共用的 WebSocket 防护；按路由限定的本机日志例外使两种访问规则保持清晰。

[INV-WEB-01] 本机日志读取边界定义在 [Web 访问契约](../../../../docs/subsystems/web-access.md)。离线测试覆盖无令牌本机日志推送与 HTTP 读取、跨来源和远程拒绝、已配置令牌的行为，以及前端连接建立。
