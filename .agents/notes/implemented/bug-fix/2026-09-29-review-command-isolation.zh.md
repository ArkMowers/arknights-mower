# 模拟器命令隔离与审查修复

[English](2026-09-29-review-command-isolation.md)

## 契约

- [INV-DEV-02] 生命周期命令隔离：模拟器生命周期命令使用不经 Shell 解释的字面参数列表，且只作用于显式确认的实例；实例控制不可用时失败，不执行全主机操作。
- 已移除的 MuMu 6 选择没有注册发现或生命周期适配器，旧命令构造器拒绝该产品。
- MuMu IPC 多段滑动保持一个触控序列。MuMu 管理器匹配要求显式索引或唯一名称；同时提供时校验两者，并拒绝身份歧义和无效端口。
- 设置页隐藏时暂停定时状态查询，按字段值比较配置而不依赖键顺序，并保留自动保存的同步依赖收集。

## 验证

离线回归测试覆盖滑动、字面命令参数、未确认生命周期操作的拒绝、JSON 身份歧义、端点别名与配置边界。现有设备、调度初始化、WebSocket 和前端定向测试验证兼容性。

[简化审查](../simplification/2026-09-29-review-boundaries.zh.md)记录保留的机制。[设备子系统](../../../../docs/subsystems/device-control.md)维护永久不变量。词汇表定义不变。
