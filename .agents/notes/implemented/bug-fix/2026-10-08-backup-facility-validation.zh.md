# 副表设施校验

## 契约

[INV-SCHED-34] 要求副表保持主表生产设施类型与岗位数。制造站、贸易站按配置岗位数校验等级。显式换人任务不得超出主表岗位，包括 Current 等占位符。关闭自动切换产物与订单时，产物与订单目标保持与主表一致。

## 实现

`validate_backup_facilities` 在组合演算前检查副表设施、显式任务及产物目标。校验报告副表名称、房间与冲突目标，返回失败状态并阻止启动，不因组合预算耗尽而放行。生产设施声明保留主表完整岗位数；非生产设施的局部人员覆盖仍保持原有语义。容量内的任务前缀仍可使用。

`Operators.swap_plan` 在改变排班、配置、干员或宿舍前，按当前切产物设置重新检查将生效的副表约束。启用失败返回错误并保留既有实际状态。切设施没有已实现模式，继续禁止，不新增预设开关。

后端配置模型、运行时兼容检查和前端配置默认值均将自动切换产物与订单设为默认关闭。旧配置缺少 enable 字段时保持关闭；明确保存的开启值在载入和序列化后保留。关闭时前端条件编辑器隐藏产物相关选项，启用后才显示。测试切产物开启路径时明确设置开关。

简化预检将静态检查保留在既有副表校验模块，由启动、手动校验与运行时启用共同复用。不新增配置结构、设施操作或界面流程。

## 验证

离线回归覆盖生产设施岗位数增加和减少、具名与 Current 岗位的设施类型变化、各类占位符任务越界、切产物关闭与开启、相同产物、合法非生产设施局部覆盖，以及运行时失败后的状态隔离。使用用户二维码解出的配置回放，第三项 Current 明确产生 room_1_3 任务越界错误。回放仅读取配置，不操作设备。

## Standards Findings

通过：复用既有主表设施信息与结构化校验结果。运行时失败发生在状态修改之前；有界声明检查不执行条件表达式。不变量在子系统契约、编码标准及审查清单登记。

## Spec Findings

通过：不支持的设施变化和关闭切产物时的目标变化不能静默进入副表。错误显式任务在组合演算前失败；执行边界继续保持既有终止行为。
