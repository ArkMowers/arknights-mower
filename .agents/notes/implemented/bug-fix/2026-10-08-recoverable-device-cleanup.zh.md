# 可恢复的设备清理

## 契约

[INV-DEV-22] Recoverable Owned Cleanup 在清理失败后保留原始资源所有者，只重试尚未完成的清理。清理成功后才清除失败并开始新的已验证启动；未解决的清理失败继续阻止资源替换。Device Profile、外部资源和共享 ADB 状态保持不变。

## 边界与简化

缓存的清理失败描述上次尝试，而非设备当前连接状态。Device Control 保留清理失败的 Device 所有者，并在关闭或恢复时重试清理。Device 只保留关闭失败的资源，已完成清理的资源只释放一次。缺少可验证所有者的清理失败不会因其他资源成功释放而被清除。现有恢复冷却和受保护的 ADB 命令提供重试边界，无需增加恢复循环或无条件清除错误。

DroidCast 将远端清理记录与宿主进程分开管理。远端操作失败时仍执行宿主进程终止和 HTTP 关闭。远端查询或终止失败保留唯一进程名；转发检查或移除失败保留所属端口。每次重试都在修改前验证进程命令行与所选 serial 的准确转发映射。被替换的进程或映射保持不变。清理命令沿用现有有限超时。

## 验证

离线隔离测试覆盖离线清理后成功恢复、重复失败的关闭、远端与转发清理责任保留、外部进程与转发身份变化、已完成宿主清理只执行一次、Device Profile 不变、未确认输入暂停保留，以及未解决失败阻止启动。现有设备归属、截图、关闭和恢复测试继续作为约束。
