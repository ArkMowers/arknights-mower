# Alpha 帮助与 FAQ 内容

## 契约

[INV-AI-01] 同时约束内置 FAQ 建议和工具提示。一条龙帮助及 FAQ 描述当前 alpha 界面，并提供用户指定的反馈表。邮件反馈仍是独立的显式操作。

## 前置简化

现有 FAQ 列表、独立帮助 HTML 和反馈组件保留各自职责。FAQ 条目附带本地来源供维护。帮助移除过时安装命令、重复导航标识、重复剪贴板监听和开发热重载脚本，不增加文档框架或提交服务。

## 实现

以当前软件及资源更新、设备绑定、任务开关、排班恢复、养成计划和配置备份说明替换旧下载器及手工迁移建议。系统提示包含安装版本，FAQ 匹配忽略拉丁字母大小写。帮助、FAQ 和反馈窗口链接至指定反馈表，不向表格提交数据。[助手契约](../../../../docs/subsystems/ai-assistant.md) 定义接口边界，[前次提示词记录](../../implemented/bug-fix/2026-10-09-ai-assistant-prompts.md) 说明工具参数对齐。

邮件提交返回反馈组件检查的成功消息，使成功发送后触发成功提示和描述复制。显式收件人列表保留原邮箱，并添加用户指定的反馈邮箱，反馈窗口和助手均使用该列表。不增加表格提交服务。

用户要求在应用仓库暂时维护最新说明，文档站 PR 保持独立。README 重新承载 Windows、Linux、macOS 源码部署，并链接[本地打包](../../../../docs/cookbook/packaging.md)及 [Docker 部署](../../../../docs/cookbook/docker-deploy.md)。一条龙按当前代码重写；帮助与 FAQ 的部署入口改回项目主页，不依赖尚未发布的文档站新页面。macOS 安装步骤准备默认 ADB 路径。手动下载仍使用主项目 Releases，后端更新源保持不变。

面向用户的帮助标题、链接文字和 FAQ 文案不再强调 alpha；项目链接指向仓库主页，不指定分支；克隆命令保留实际分支名。帮助和 FAQ 中的手动安装包下载指向主项目的 Releases 页面，后端更新源保持不变。

DeepSeek 合并为一个服务选项，支持预设或自定义模型。独立模型字段使服务切换时保留本地及在线自定义接口设置。[助手契约](../../../../docs/subsystems/ai-assistant.md) 维护模型 ID 和旧选择迁移规则。移除原按模型分派的映射，沿用现有模型工厂和密钥解析。本次复用 [INV-01] 的显式字段持久化要求，不增加不变量、抽象或术语概念。

一条龙通过浅色、暗色语义配色覆盖正文、导航、链接、表格、代码和提示框。嵌入页面跟随 Mower 主题切换且不重载，单独打开跟随系统偏好，并支持查询参数显式选择。主题同步只接受经过校验的同源父页面消息。独立的排班理论章节补回字段职责、三岗位完整替班示例、心情上下限与阈值说明、工休时间估算、副表叠加和编写检查顺序；示例已对照当前编辑器及排班契约核对。

一条龙视觉修复通过既有父页面消息复用 Mower 当前主题颜色，仅接收允许的颜色属性，不增加第二套配色服务或持久化设置。独立页面默认色对应当前 Mower 配色。页面移除渐变，采用正文、卡片和控件背景，限制阅读宽度，正文使用 14 像素并左对齐。三个重复提示框样式合并为中性背景、语义侧边色条、对称内边距及无末段外边距的共用样式。过渡明确指定属性，并遵循减少动态效果偏好。本次保留 [INV-01] 与既有主题消息校验，领域概念不变，无需生命周期迁移。

帮助容器移除正文上方额外的标题、反馈链接及文档站原始网址，直接显示一条龙。正文反馈章节和既有反馈窗口保留表格入口；来源检查验证这些保留入口，不再要求容器重复放置链接。

排班编写示例区分普通替班、同组工作与宿舍主班互替，以及显式 Free 临时开放床位。恢复容量计算纳入固定恢复位且不重复占用动态床，宿舍跟随成员和零心情工作干员不计入普通恢复需求；主表保留 Free 连续及每间至少一个 Free 的要求，不限定宿管人数。多绑组示例说明逐组候选、单绑组工作计时成员及并行休息的共同候选。一条龙和 FAQ 还说明整岗位 Current 继承、副表名单增减、分床优先级、个人及令夕与全体心情设置的优先顺序，以及编辑器本地三设施布局。本次修正教程覆盖不足，不修改调度行为或术语定义。 新说明依据[排班契约](../../../../docs/subsystems/base-scheduler.md)中的保床和绑组额度规则，补充普通固定工作主班条件及[训练位预检](../../../../doc/plan-roster-validation.md)；FAQ 同步这些变化，不修改排班逻辑或术语定义。

聊天面板沿用现有助手组件及主题变量，补充标题栏、只填入草稿的话题入口、多行输入、完成回复操作与按阅读位置滚动；收起保留当前对话。响应式 CSS 替代窗口尺寸监听，组件卸载时清理连接和计时器。紧凑桌面面板支持通过标题栏拖动，使用指针捕获并限制在视口内；位置仅保存在临时状态中。标题栏按钮保留点击行为，窄屏保留全高布局。WebSocket 增加完成帧，使进度片段期间保持忙碌，完成或失败后才允许下一轮。模型设置重新组织现有字段，不修改持久化规则。本次复用 [INV-01] 和 [INV-AI-01]，不增加术语概念或独立记录。

此前文档拆分通过七项提示词及帮助定向测试和九项子测试。本次恢复共同检查仓库文档与嵌入帮助。未执行跨平台安装、打包或容器运行；部署命令对照当前启动入口与构建文件核对。

DeepSeek 维护通过 AI 功能及提示词定向测试 18 项、16 项子测试，以及三项前端配置检查。旧 Flash / Pro 选择保留对应模型和密钥，自定义 ID 发送至官方接口，Pro 思考参数保持有效，空 ID 在构造模型前被拒绝，序列化不增加未选择的默认值。前端检查覆盖预设和自定义 ID 加载、仅保存修改的服务或模型字段，以及无关设置保留。设置组件脚本及模板编译和格式检查通过，未发送真实模型请求。

主题验证通过九项前端定向测试，覆盖系统默认及变化、显式主题、父页面消息校验，以及不重载 iframe 的主题更新。CSS 解析及 34 项文字背景对比检查通过 WCAG AA，浅色最低 4.56:1、暗色最低 7.04:1。帮助导航及来源检查通过。浏览器工具禁止访问本地文件 URL，本次主题更新没有浏览器视觉验证证据。

排班文档验证通过 59 项定向测试及九项子测试，涵盖提示词及导航检查与现有排班回归中的选定案例。覆盖同组主班身份与完整匹配、固定及动态恢复容量、宿舍跟随成员、多绑组交集及校验、共享临时 Free 开放周期、可变宿管人数、副表 Free 布局、名单有序增减和心情限制优先级。治理及 FAQ 静态和格式检查通过；检查均为离线执行，不操作设备。

聊天 UI 的 15 项交互定向测试及三项既有 DeepSeek 部分保存测试通过。后端六项测试和十一项子测试覆盖鉴权流式回复、全部片段后的完成帧、空回复及模型失败。浏览器检查覆盖浅色及暗色桌面、话题草稿、流式状态和反馈入口；390×844、320×568 下无横向溢出，输入区保持可见，聊天操作按钮高度为 40 像素。重新打开的预览无控制台错误。本地前端生产构建通过，已应用的程序文件与审查工作树一致。预览使用模拟回复，Mower 后台实例保持关闭，不连接模型或设备。
