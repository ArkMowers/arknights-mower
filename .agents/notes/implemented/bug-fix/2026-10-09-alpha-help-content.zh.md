# Alpha 帮助与 FAQ 内容

## 契约

[INV-AI-01] 同时约束内置 FAQ 建议和工具提示。一条龙帮助及 FAQ 描述当前 alpha 界面，并提供用户指定的反馈表。邮件反馈仍是独立的显式操作。

## 前置简化

现有 FAQ 列表、独立帮助 HTML 和反馈组件保留各自职责。FAQ 条目附带本地来源供维护。帮助移除过时安装命令、重复导航标识、重复剪贴板监听和开发热重载脚本，不增加文档框架或提交服务。

## 实现

以当前软件及资源更新、设备绑定、任务开关、排班恢复、养成计划和配置备份说明替换旧下载器及手工迁移建议。系统提示包含安装版本，FAQ 匹配忽略拉丁字母大小写。帮助、FAQ、反馈窗口和 README 链接至指定反馈表，不向表格提交数据。[助手契约](../../../../docs/subsystems/ai-assistant.md) 定义接口边界，[前次提示词记录](../../implemented/bug-fix/2026-10-09-ai-assistant-prompts.md) 说明工具参数对齐。

邮件提交返回反馈组件检查的成功消息，使成功发送后触发成功提示和描述复制。显式收件人列表保留原邮箱，并添加用户指定的反馈邮箱，反馈窗口和助手均使用该列表。不增加表格提交服务。

README 保留简介、截图、Windows、Linux 和 macOS 源码部署、反馈入口及项目声明，移除其中的打包、发布细节、开发检查和 Docker 说明。源码步骤采用前端当前要求的 Node.js 版本，并提供直接启动命令；Linux 依赖错误提示指向现有平台文档，不再引用已移除的打包章节。

## 验证

定向离线检查覆盖旧下载器提问、当前任务开关及数据库清理建议、FAQ 大小写匹配、本地来源和帮助导航。本次不修改排班机制、设备控制或配置结构，无需修改术语表。

README 维护验证本地链接及章节锚点、Bash 语法（不执行安装）、前端锁文件中的 Node.js 要求，并通过四项帮助链接和 Linux 依赖提示定向检查。未执行跨平台安装。
