# DroidCast 目标消失后的清理

## 契约

[INV-DEV-16] Absent Target Cleanup 在所选目标消失且没有自有转发残留时，允许 DroidCast 幂等清理及后续已验证启动。未知传输错误、自有转发残留和主机资源清理失败仍阻断启动。其他程序资源和共享 ADB 状态保持不变。

## 边界与简化

现有 DroidCast 清理边界仅在明确允许的清理命令中，将精确匹配所选设备的未找到响应归类为远端辅助进程不可用。截图和安装失败保留原有分类。转发清单通过不带设备选择器的受保护服务端读取获取；移除操作仍绑定所选 serial，并要求精确匹配自有映射。移除失败后，只有再次受保护读取确认该映射不再属于当前会话，清理才成功。

目标消失后仍执行主机进程终止及 HTTP 关闭。设备控制清理失败保护保持不变：真实清理失败仍禁止再次启动。不新增厂商分支，不重启共享服务，不全局移除转发，不无条件清空错误缓存。设备配置和实例绑定保持不变。

## 验证

离线测试覆盖目标消失、其他程序映射保留、重复关闭、下一次已验证实例启动、移除与断连竞争、自有转发残留、受保护主机清单、格式无效或不可用的清单和未经确认的离线传输。现有权限拒绝、进程身份变化和主机资源清理测试保持有效。

只读预检截图测试要求每条命令使用已验证的 ADB 程序。只有精确匹配的服务端 `forward --list` 清单读取省略设备选择器；其他截图与清理命令仍绑定所选 serial。
