# 重启后保留独立干员回满休息

开启测试宿舍逻辑时，未编组且同时设置用尽与回满的干员，在纠错找不到可用替班时继续尚未完成的宿舍恢复。上班任务丢失不代表本轮恢复结束。

纠错复用现有休息成员判断与替班选择；正常规划通过 `plan_metadata` 按床位回满时间重建上班任务，不增加持久状态或独立计时实现。已回满、有可用替班、编组纠错和旧宿舍逻辑保留现有规则。

离线测试覆盖任务丢失、干员缓存恢复、缺失及保留的回满时间、重复规划、12/20/24 的有效上限，以及恢复完成。
