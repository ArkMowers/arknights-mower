# 在继承写入期间保留命令输出

[English](2026-10-03-command-output-review-repairs.md) | [中文](2026-10-03-command-output-review-repairs.zh.md)

## 契约

[INV-DEV-20] 在后代保留并写入继承句柄期间保持捕获输出完整。收集不改变写句柄的文件位置，保留已有字节，并在命令现有期限和清理额度内返回。[设备控制](../../../../docs/subsystems/device-control.md)定义接口契约。

## 实现

`run_command` 为有名临时输出文件使用独立打开的读句柄。`_capture_stream` 以一对流为单位创建它们，两个通道共用临时文件、独立读句柄与 Windows 删除共享策略，不重复实现。Windows 读句柄与临时写句柄共享删除访问权限。实现只终止自有命令，后代和共享服务保留既有生命周期。不新增线程、重试、配置字段或外部依赖。

BlueStacks Air、I/O 预算和会话调用方测试在消费模块中模拟执行函数。预算夹具返回 `CompletedProcess`；Shared ADB Guard 不兼容测试在创建进程前拒绝截图和 MaaTouch 启动。

审查轮次收紧共用契约。输出超限报告 `CommandOutputLimit`，它同时是 `ValueError` 与 `subprocess.SubprocessError`，因此会话按设备判定处理而不当作应用故障。`universal_newlines` 与 `text` 一样选择文本输出，`stdin=PIPE` 立即收到 EOF（等同无输入可写时 `communicate()` 的关闭），`input` 在创建进程前被拒绝。继承句柄夹具的命令期限高于合成命令启动耗时，覆盖不再依赖机器负载。

最后一轮审查处理其余条目。管理器输出超限保留共用异常类型，并在判定中写明调用方需要的修复步骤。`run_manager_command` 接受命令调用形态中它本就满足的部分，其余参数一律拒绝而不再静默丢弃。超时部分输出沿用调用方的二进制/文本选择；无法解码的片段保留原始字节，因为部分输出的解码失败不得顶替命令报告的超时。MuMu 输入版本查询以替换方式解码，厂商诊断里的个别字节不再让版本读取失败。`ProductionSimulator` 按管理器类别选择生命周期执行器，注入的执行器原样使用，不再比较函数对象是否等于默认值。设备命令超时导致的截图失败改为指出该命令，而不是所选截图后端。MuMu 空闲断开也不再显式指定管道执行器，由受保护路由的默认有界执行器执行，与本题范围内其它 ADB 命令一致。该选项的设置页标签、配置注释与问答条目改为描述它现在执行的断开，而不再是已移除的进程终止；持久化键名保持不变。

## 验证

离线夹具写入初始 stdout/stderr，由后代保留两个句柄，并在读句柄定位与读取之间同步追加写入。断言覆盖成功完成、退出码失败、超时部分输出、分离与合并通道、自有进程清理，以及后代退出后的临时文件删除。定向调用方测试覆盖更新后的执行接缝。

定向离线验证通过 529 项测试和 163 个子测试。六个继承写入场景在修复前全部失败，修复后全部通过。Ruff 检查和格式检查、仓库治理与 diff 空白检查均通过。审查轮次将 `device_command_tests.py` 扩展到 36 项测试，覆盖输出上限判定分类、`stdin` EOF、拒绝 `input` 与 `universal_newlines` 文本输出；继承句柄夹具重复运行不再出现期限抖动。

最后一轮将 `device_command_tests.py` 扩展到 43 项测试，定向套件达到 388 项测试与 135 个子测试。新增覆盖：管理器修复步骤与被拒参数、共用命令调用形态、文本模式与无法解码的超时输出、各管理器类别选择的生命周期执行器，以及超时截图的文案；后两项分别落在 `device_screenshot_backend_tests.py` 与 `device_session_io_tests.py`。

## 规范审查

通过：独立读句柄保持继承写句柄的位置不变。现有清理栈在成功、进程启动失败、读句柄打开失败和命令失败时关闭两个句柄。调用方夹具替换其消费的执行函数，并拒绝意外进程创建。管理器执行器声明其合并、校验契约本就满足的参数并拒绝其余参数，输出超限与命令超时始终是设备判定。

## 规格审查

通过：成功结果、退出码失败和超时部分输出在后代写入期间保留已有字节，覆盖分离与合并通道。命令期限、输出上限、文本解码、Shared ADB Guard 与 Instance Binding 保持既有契约。管理器输出超限保留修复步骤，超时截图指出命令而非所选后端，注入的生命周期执行器仍原样取代默认值。
