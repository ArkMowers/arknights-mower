# MAA 核心代次校验

## 契约

[INV-UPD-02] 在连接前验证桌面核心身份与版本。[MAA 运行契约](../../../../docs/subsystems/maa-runtime.md) 定义初始化与失败边界。进程常驻核心改变时要求重启 Mower 进程；仅资源改变时保留正常加载。不强制卸载 native 句柄或回调。

## 简化

调度器中单调用点的嵌套构造包装交给一个受测试的加载器，继续使用已有更新事务。加载器复用文件身份、独立版本探测和验证实例接口，不增加配置开关、恢复工作线程或排班状态。

## 验证

离线回归覆盖首次加载已常驻旧映像、版本号不变的外部替换、探测过程中变化、资源加载失败、版本探测失败、不变核心复用、仅资源更新、忙碌实例、缺失核心以及托管更新后的 SDK 重新导入。私有运行追踪不进入公共补丁。

## 规范审查

通过：native 所有权保留在 SDK 内，设备传输与排班计划不变，每个 SDK 类仅记录一个代次条目。定向测试通过 172 项及 25 个子用例，治理检查通过。独立 native 初始化接受配置主题，不取得设备连接或启动任务。

## 需求审查

通过：连接前实际运行版本与独立磁盘探测版本一致；外部核心变化在资源加载前被拒绝。重启提示区分进程重启与自动化任务重启。不增加 native 卸载或自动重启应用行为。
