# 会话配置与恢复审查修复

[English](2026-09-29-session-review-repairs.md)

## 契约

- [INV-01] 与 [INV-03]：启动时检测到的游戏包和端点属于会话。初始化失败及无关设置保存均保留用户的设备配置（Device Profile）。
- [INV-04] 与 [INV-UI-01]：后端即时编辑以已保存配置计算联动字段，未经确认的身份编辑保留在组件草稿中。
- [INV-DEV-03]：实例命令的超时取自身剩余期限、外层恢复预算（Recovery Budget）和单条命令上限中的最小值。
- [INV-DEV-07] 截图恢复隔离：正常截图使用独立的单次操作期限；降级后的 ADB 后端验证绑定目标时不调用已替换的截图助手。
- [INV-REC-03] 场景恢复上限：每次导航遇到持续场景转移异常时最多重启游戏一次，之后抛出识别失败；取消和设备故障立即向上传递。

## 边界

设备持有经验证的运行选择，供游戏命令、截图、触控和 MAA 使用。持久化配置仍记录显式选择。一次恢复事务中的就绪检查与截图工作共享同一期限。

MuMu 空闲关闭只断开自有客户端的端点。会话已关闭或客户端已释放时跳过传输清理，不用已保存端点替代缺失的运行目标。

场景导航复用应用的设备恢复和求解器的游戏重启，不增加模拟器生命周期命令，也不重复发送结果未知的输入。

现有词汇表中的 Device Profile、Instance Binding、Readiness Verdict 和 Recovery Budget 定义覆盖这些修复。配置结构和领域术语没有新增项。

## 验证

离线回归测试覆盖初始化失败后的无关保存、恢复期限结束后的正常操作、原截图助手不可用时的 ADB 截图、实例命令递减期限、预设往返切换后的后端配对编辑，以及场景重启耗尽。
