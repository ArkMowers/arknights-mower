# 同名形态共用基建技能

## 契约

[INV-SCHED-09] 让同名形态共用按姓名索引的基建技能目录。已持有形态中的最高有效练度证明技能解锁；缺失形态记录不使已知练度失效。不以形态 ID 清单限制未来形态。

## 简化

部分技能快照保留已知合格替班。已知候选足够且固定驻员技能明确时不扫描卡牌，否则在既有预算内补充候选。新卡牌读数替换对应候选的缓存结果，包括排除低心情候选。[排班契约](../../../../docs/subsystems/base-scheduler.md) 定义选人规则。[INV-SCHED-15] 保持估算与实测恢复证据分离。

## 验证与审查

Standards Findings：无未解决问题。共用 BOX 保持只读，实测心情及选人时资格检查保持有效。不增加形态注册表或持久化候选缓存。

Spec Findings：无未解决问题。定向离线验证通过 482 项测试及 4 个子测试，覆盖未来形态、练度缺失、部分快照及补扫中的低心情排除。
