# 自带 ADB 默认路径

## 契约

[INV-DEV-21] 未显式指定 ADB 路径的设备配置使用与旧配置相同的平台默认值。Mower 自带的可执行文件优先；显式路径和显式空值在无关配置更新及保存重载后保持不变。

## 实现

`DeviceProfile.adb_path` 与 `Conf.maa_adb_path` 共用设备配置模块中的 `default_adb_path`。统一默认值无需额外配置迁移或前端路径选择规则。自带路径保留可迁移的 `@internal/platform-tools/` 别名。Linux 在自带文件不存在时保留环境变量与 PATH 默认值。读取默认值不会将设备配置字段标记为显式选择。

## 验证

前端依赖声明和锁文件使用 Prettier 3.9.9，与当前 CI 格式工具一致。本地前端格式检查使用该已安装版本。

离线配置测试覆盖 Windows、macOS 和 Linux 的自带文件、未填写路径、显式自定义路径与空值、无关配置更新及保存重载。设备配置和预检测试检查现有选择及校验规则的兼容性。

额外运行的会话 I/O 测试在共用默认值与原有空默认值下均报告相同的 34 个失败项，含子测试。这些既有路径及管理器测试数据问题不属于本次改动。
