# 跨渠道 OTA 升级

[INV-UPD-06] 将安装版更新渠道定义为可接收版本的范围：开发版接收 Nightly、公测版和正式版；公测版接收公测版和正式版；正式版只接收正式版。更新且可安装的公开版本替换当前更新目标，保存的渠道选择保持不变。开发版与公测版的主渠道索引失败仍报错；正式版保留 GitHub Latest 回退。可选渠道失败保留主渠道结果。现有各渠道索引格式继续兼容旧客户端。

`latest_release_index` 复用语义版本比较和完整包校验。选中目标同时提供完整包与精确匹配起点版本的 OTA。发布端为公测版保留有界数量的近期 Nightly 起点，为正式版保留近期公测版和 Nightly 起点。修复移除发布端对 Nightly 的统一排除，不增加包格式、安装器或渠道配置项。

专项测试通过实际更新检查入口验证渠道选择保留、精确起点 OTA 选择、正式版渠道隔离、同版本判断、可选索引失败和不兼容包。现有 Nightly 方向判断、回退确认及重建测试保留原有保证。MowerRelease 与 Android 配套测试验证生成端起点配额及 Android 选择逻辑。验证通过：桌面端、源码与 OTA 专项 110 项测试、165 项子测试；发布端 27 项测试、13 项子测试；Android 端 23 项测试、30 项子测试。真实 Nightly `g85e916f7` 到 alpha.11 生成 2,430,022 字节 Windows OTA 和 23,479,114 字节 Android OTA。Windows 重建文件与目标一致；Android 重建的 3,130 个 Mower 文件及 10,396 个运行时条目、权限和摘要与目标一致，并通过安装包检查。运行时重压缩改变容器摘要，只同步修改清单中的对应摘要；运行时内容保持一致。未进行实机安装。

规范审查：保留现有有界请求、规范路径检查、校验值与完整包回退；术语表概念不变。需求审查：更新的公开版本无需修改渠道即可被发现，生成精确起点的跨渠道 OTA，同版本不重复安装，不受支持的可选资产保留主渠道结果。
