# ADB 锁字节测试兼容性

## 契约

[INV-DEV-19] 在重启尝试前保留共享服务代次，包括停止失败及其他协调器的观察。[共享 ADB 恢复决策](../../implemented/simplification/2026-10-01-shared-adb-recovery.zh.md) 定义保持不变的生产边界。

停止失败测试在协调器持有租约期间，通过另一只只读文件句柄从字节一读取持久化 JSON。Windows 字节区间锁保护字节零；检查 JSON 正文不需要读取这个已锁字节。测试保留停止前代次持久化、结构化停止失败和其他协调器观察代次的断言。

## 简化

测试先跳过锁字节，而不是读取整个文件后再切片。不增加生产分支、辅助抽象、测试跳过、平台排除或锁放宽。既有不变量登记与词汇定义保持不变。

## 验证

参数化测试分别使用普通文件读取和拒绝整文件读取的故障注入，两条路径断言相同的停止失败及其他协调器观察代次契约。针对性共享服务测试与仓库治理验证修正；现有桌面 CI 矩阵保留 Windows 原生执行。
