# Shared Plan Group Colors

The plan store owns one color map for the main plan and all backup plans. The twelve avatar rendering sites reuse that map instead of assigning colors from the active table. Multi-group avatars use a bottom-only background strip and keep the neutral avatar background; equal segments include unfinished columns.
