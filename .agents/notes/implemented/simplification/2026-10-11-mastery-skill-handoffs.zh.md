# 跨技能专精衔接

## 契约

[INV-SCHED-47] 将符合条件的同干员技能排为相邻，未开始技能按当前专精等级升序排列，仅在共享库存及允许配方能合成联合剩余需求时开始，实际仅筹备当前技能的材料。当前技能的最终阶段在下一技能属于同干员且已达专一时安排减半干员。协助位身份实读一致且记录训练超过五小时，才确认跨技能继承减半。

既有[排班契约](../../../../docs/subsystems/base-scheduler.md#3-subsystem-invariants)同时约束任一阿米娅专精选择的提示和每次进房的升变检查。显式形态 ID 保留用户选择的技能，避免同名形态混淆。升变不符时保留可靠实读的减半干员，跳过本次进房的修改动作，后续进房继续检查；确认目标技能后恢复执行。此改动不增加自动升变切换或永久暂停训练室。身份检查复用 [INV-REC-05]。

同干员下一技能为七级升专一时，专三不使用减半干员持续协助，即使其加成最高。开始时先消费已确认继承的减半，再更换协助者；恢复与已入队换人执行相同的路线限制。队列编辑后重新判断限制，不再适用时恢复通常的减半干员保护。

## 简化证据

`stage_route` 与 `schedule_support_swap` 共用五小时减半出勤要求及默认十分钟缓冲。三个旧缓冲键保留读取兼容，默认值均为十分钟，显式设置保持用户选择。中枢换班确认后刷新实读倒计时及待执行换人时间。减半干员的出勤预留包含配置中的全程中枢加成，当前训练进度按实际在岗情况计算。

## 验证

离线定向测试覆盖相邻排序、单技能材料准入、最终阶段减半准入、跨技能出勤记录、默认缓冲及中枢换班后的任务时间更新。训练位保护和实读技能归属约束保持生效。

前端页面定向测试覆盖任一阿米娅形态选择、多形态、筛选、移除、已保存计划重载及单技能和批量提交的形态 ID。阿米娅升变测试覆盖派发遇到错误形态后在后续正确形态下恢复、不可读文本的有限重试、取消与设备恢复异常传播、反复进房检查、跟随排班时禁止修改以及显式全部职业选人。真实 OCR 读取三个形态的离线渲染技能名；游戏截图验证仍待完成。衔接测试覆盖下一技能从七级开始时，专三选择并换入非减半干员、继承减半以及队列编辑。既有接口与任务契约证据覆盖同名形态分别解析及无效显式 ID 拒绝后不回退到姓名匹配。
