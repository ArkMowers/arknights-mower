# Mower 自动救急

## 契约

[INV-SCHED-09] 保留原生救急进入判定与实测恢复目标。可选自动救急由 Mower 安排临时驻员，无需外部协助。候选当前卡牌心情须可读且不低于个人正常下班线加一点。跑单干员不获得普通临时工作岗位；符合正常条件的跑单持续调度，并恢复实测临时原班。

各设施读取实际产物。自动专精与基建技能共用原有森空岛同步接口、BOX 文件与干员读取缓存，同一快照提供持有、精英阶段和等级；文件变化时两边缓存共同失效，无需独立身份标记。按技能组替换规则确定已解锁版本；缺少练度数据时识别卡牌生效技能图标。制造与贸易设施比较支持的设施内技能组合；发电、办公室、会客室与中枢使用各自评分。未知效果与跨设施联动不假设收益。各房间共用候选预约与已选姓名集合。宿舍及训练室保留专项安排边界。合格人数不足时明确留空。

救急冻结普通换班及副表切换，持久化未完成的临时安排与退出交接，重启后核对实际设施。心情复查只替换缺员或新近不合格的临时工作者，并继续普通收取。主班恢复、宿舍优先级、肥鸭、加工、训练与实测退出保留既有契约。


选人仅比较有界候选集合内已支持的效果：制造与贸易最多 48 人，其余设施最多 16 人。评分用于近似效率，不声明涵盖全部技能或干员的最优组合。

## 简化

移除救急专用的 MAA 连接、派发、回调及停止生命周期。未上线的配置与快照字段直接改名，不增加别名或兼容迁移。复用既有选人、资源重载、跑单原班恢复、宿舍规划和历史数据。基建技能页使用同一套已解锁版本，标记未拥有、未解锁及已替换条目，并按设施、持有、技能状态与文本筛选。缺失数据时不显示干员或技能状态标记。

## 审查

Standards Findings：候选集合与图像识别有明确预算；已确认练度或生效图标避免假定精英技能已解锁。移除外部设备控制者及重复恢复路径。

Spec Findings：临时选人排除所有跑单干员、低心情或卡牌心情不可读者、本轮恢复的主班及专项预约。临时修复之外保持工作阵容，跑单沿用正常资格并恢复临时原班。


验证：相关离线 Python 测试通过 581 项，最终自动救急回归通过 49 项。四个前端套件通过 34 项，生产构建通过。治理与自动救急合跑通过 63 项及 4 个子测试；三个治理门禁、定向 Ruff、Prettier 和差异空白检查通过。未执行真实设备集成测试。

共享读取回归确认专精与基建技能查询只解析文件一次，同步文件变化后两边一起刷新。既有专精同步数据不需要重新下载。
