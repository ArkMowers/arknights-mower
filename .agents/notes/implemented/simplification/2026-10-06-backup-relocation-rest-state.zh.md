# 副表岗位迁移保留休息状态

同一主班迁移复用现有副表替班匹配与切换边界。独立副表检查和完整换班推演均使用此边界，不新增规划器。

[INV-SCHED-28] 将状态保留扩展至相同设施类型且有序绑组不变的主班岗位迁移。在岗主班转移至新岗位；休息主班保留床位和回班时间，由可用替班转移或接替。切入副表的显式换人任务保持优先。切出恢复岗位时使用替班，不强制召回受保护的休息主班。任务预留、专精保护和无关岗位占用约束持续生效。

## 验证

离线回归覆盖下班触发岗位迁移、另一组仍休息时退出副表、替班迁移、显式切入任务与受保护的替班不足场景。
