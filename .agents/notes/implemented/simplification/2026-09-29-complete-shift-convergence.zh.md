# 完整换班收敛

## 契约

测试宿舍的动态换班在提交一次最终安排前，收敛副表条件、可下班组、缓存纠错及最终空床补位。规划复用 `resting`、`try_reorder`、`_prepare_shift_backup` 和 `try_add_release_dorm`，不新增候选排序规则。工作岗位迁移不等同于休息后回班；本轮实际回班者及其整组不会立即再次下班。

[INV-SCHED-05] 完整换班预演要求副表条件与最终驻员同时稳定。重复状态或超过迭代上限时，在提交任务或真实驻员前抛出 `ValueError`。初始化心情补读、肥鸭充能、切产物预约以及临近跑单和专精任务保留原调度边界。游戏选人的 `Free` 尚无已知驻员，在实际选人时读取后再依据新信息判断。

空床检查仅在 `resting` 生成下班安排（含宿舍槽位）时进入完整收敛；否则保留只补空床的流程，工作纠错由原入口处理。预演深拷贝调度状态并复用表达式校验模型，不复制求值时注入的 Python 运行时内建对象。

肥鸭临时进出宿舍保留实测工作心情消耗速度，正常心情采样更新心情和时间戳。后续工作读数继续按 [INV-SCHED-01] 校准消耗速度。

## 简化依据

`infra_main` 提交普通换班，`run` 检查空床；此前两个入口的副表预演、补床独立于下一次 `resting` 规划。二者共用 `_prepare_shift_cycle`，候选顺序、床位优先级和替班合法性沿用已有实现。副表宿舍迁移以已提出的槽位改动为比较依据，防止中间安排覆盖原住者而未补回其床位。

## 验证

`shift_cycle_convergence_tests.py` 覆盖回班触发后续轮休、缓存隔离、失败回滚、关键任务保护，以及六张副表、日志缓存与稍后回班意图构成的规划场景。该夹具是规划场景重建，不是完整设备回放。已有副表回放与宿舍测试验证最终岗位合法性及保床；充能回岗读房测试验证消耗速度保留。空床回归覆盖入住限制、关键任务时间及先轮休后补床；不可复制的运行时内建对象验证表达式模型复用。
