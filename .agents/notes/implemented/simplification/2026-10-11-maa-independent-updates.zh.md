# MAA 独立更新

[English](2026-10-11-maa-independent-updates.md)

两类自动更新策略均遵守[独立更新准入规范](../../../../docs/subsystems/maa-integration.md#independent-update-admission)，历史引用为 [INV-MAA-10]。

简化审查确认 `MaaBasic.vue` 只有一个合并的自动检查入口，后端已有两个更新接口。策略在原入口内分别判断本体与资源，并复用已有接口、互斥和回退副本，不增加更新线程机制或安装器。

本体与资源分别保存自动检查和自动更新开关。新配置的四个开关默认关闭。旧的合并自动检查配置迁移为两个检查开关，不启用自动安装；显式资源配置在重载后保持。进入设置页或修改相关配置时执行检查。自动安装须显式开启、通过当前检查，并遵守已有的 MAA 空闲检查。检查期间关闭策略、切换目录或更新源后，旧响应不触发自动安装。

本地资源时间未知时，有效的已发布资源时间仍可安装；检查结果继续绑定目录、更新源及观察到的本地版本，且只消费一次。连接预设读取与资源加载失败时区分配置文件缺失、格式无效和访问被拒绝。资源合并仅在暂存副本内开放待覆盖文件的写入权限。

[MAA 集成规范](../../../../docs/subsystems/maa-integration.md)定义接口规范。离线测试覆盖独立策略、旧配置迁移、未知版本、检查绑定与文件访问失败。

规范轴与需求轴审查确认持久化选项独立、旧响应被拒绝，并保留已有的引擎空闲准入和回退副本所有权。策略、更新路由、资源安装、MAA 准入、连通性及配置定向测试通过。前端组件、策略配置与部分保存测试通过 67 项。治理检查通过，保留两项未变更的历史归档引用警告。反馈中的 Windows 文件 ACL 失败仍需在对应机器验证。
