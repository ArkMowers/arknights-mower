# 连接性能建议

[English](2026-10-09-connection-performance.md)

## 契约

[INV-DEV-23] 性能观测隔离：连接测试只通过有界只读命令读取已核验且启动完成的目标性能信息；信息不可用时保留就绪结果，取消继续传播，建议未经用户编辑不修改持久化选择或时间参数。

连接表单包含现有性能选择项。Android 在连接由应用管理的提示旁保留该选择项。核验目标和启动状态后，预检通过一次受保护的 ADB shell 命令读取在线 CPU 范围和 `MemTotal`，最多三秒且受调用方的连接恢复预算限制。无效或不可用的数据产生 `unavailable` 性能观测。观测仅临时保留，目标编辑清除其显示。普通 ADB 调用在执行时读取默认命令超时；性能查询使用显式三秒上限。

建议使用 Android 可见的 CPU 核数与内存总量，不使用主机资源或截图耗时。少于两核或 1792 MiB 建议 `low`；少于四核或 3584 MiB 建议 `medium`；其他有效数据建议 `high`。内存阈值为 Android 预留内存留出余量。硬件观测不建议 `xhigh`，因为这些数据不测量游戏反馈。用户明确采用建议，或保留手动及自动选择。现有自动反馈策略和数值时间参数保持不变。

## 简化检查

设置页包含一个性能选择项和一个档位更新函数。设备预检已核验目标身份和启动状态，I/O 适配器已提供受保护的 ADB 与截止时间传播。实现复用这些边界，不增加接口、持久化硬件缓存、性能测试工作进程或策略类。共享组件服务桌面连接表单与 Android 设置，避免复制选择行为。

## 验证

离线测试覆盖 CPU 范围解析、内存阈值、固定目标 ADB 参数、有界执行、不可用数据、就绪与取消隔离、明确采用建议、Android 限制和过期观测清除。现有性能测试验证自动选择与时间参数保留。

基于 alpha `9021f4de` 的验证通过 161 项定向 Python 用例、182 项定向前端用例、前端发布构建、变更文件 Ruff 与 ESLint 检查、格式检查和治理结构检查。治理检查保留两条历史归档引用提示。设备行为使用离线适配器验证，未运行真实模拟器测试。

默认超时回归在模块导入后修改命令预算，检查实际 ADB runner 参数，并验证显式性能上限保持原值。现有继承输出进程回归验证一秒超时返回时不等待持有输出流的后代进程。

超时修复通过命令输出所有权、设备性能、预检、预检 I/O 与设置 HTTP 路由五个文件的 138 项定向用例，以及变更文件 Ruff 检查和治理结构检查。继承输出失败与确定性的默认预算用例均在修复前复现，修复后通过。
