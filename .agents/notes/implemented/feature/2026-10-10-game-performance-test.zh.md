# 游戏内选人性能测试

[English](2026-10-10-game-performance-test.md)

## 决策

桌面端显式测试独占一次设备运行，使用宿舍一，不确认换人。复用设备控制的实例启动、游戏前台启动和正式场景图导航进入基建；已在基建首页或该宿舍房间页时直接继续。登录验证、协议提示和尚未确认的既有操作需手动处理后重试。安全准备先确定连续向后滑动三次后才新到达的两个目标。每次独立选人测试均清空暂选并复位列表，再按候选档位连续向后滑动三次后选人、重排并核验名单；中间扫描只读取按住终点的画面，不选择干员。一次完整选人操作计为一次测试，连续三次成功后推荐该档；首次失败立即降一档重新测试，低档失败则不给出建议。设备故障、导航或准备失败、取消直接中止，不作为性能降档依据。

测试不设总时限，使用有限轮次、保留单次操作期限的可取消 I/O 和独立十秒的有界清理。正常结束或普通取消时取消暂选；退出程序或设备不可用可能阻止清理，并报告该情况。测试不确认进驻，不修改已保存档位、独立时间参数或自动反馈。明确采用后仅保存所选档位。设备或时间参数编辑使建议失效。连接资源读取在界面仅作为信息展示。

## 简化与记录归属

连接资源观测记录负责只读资源观测，本决策独立负责用户发起的输入测试。实现复用现有工作线程生命周期和设备运行边界，与正常排班共用选人和重排原语。不增加持久化测试缓存或第二个设备所有者。现有领域定义保持不变。

## 保证与验证

[INV-SCHED-45] 选人性能测试隔离约束有界逐级测试、明确采用和进驻及状态保留。离线验证覆盖成功、首次失败降档、全部档位失败、误选、未翻页、准备或设备故障、取消、清理、工作线程准入和过期界面结果。正式快速扫描与名单读取会拒绝日志中目标乌尔比安、斯卡蒂，实际猎蜂、斯卡蒂的误选。正常排班与显式测试共用重排坐标和时间策略。

八个后端定向套件通过 198 项用例，六个前端套件通过 188 项用例。接入按住滑动终点截图后，六个选人定向套件通过 172 项用例。取消修复新增回归，先复现设备 I/O 中取消导致会话提前关闭的问题；修复后测试、会话、关闭与按住滑动截图五个定向套件通过 86 项用例。前端发布构建、变更文件 Ruff、ESLint、格式与治理检查通过。治理检查保留两条历史归档引用提示。

本地 MuMu Pro 使用 DroidCast 截图和 scrcpy 输入，极高档连续三轮通过，实际选中名单与重排结果均通过校验；清理后宿舍仍为空，进驻人数为 0/5。第二次实测发现取消导致会话提前关闭；修复后，在已完成两轮时取消，正确返回已取消并退出选人页，进驻人数仍为 0/5。修复后再次完整实测，极高档三轮仍全部通过，清理后仍为 0/5。保存的档位与时间参数保持不变。降档与误选拒绝使用离线回归验证，本机极高档实测未失败。

测试通过设备运行边界显式延后取消时的会话关闭，先完成有界放弃暂选。普通运行的取消与进程关闭门禁保持既有行为。

自动进入回归覆盖正式快速登录和基建导航路径、已在基建时直接继续、手动验证边界，以及对短暂登录匹配重新取帧而不点击。长时间求解器与 HTTP 工作线程回归将模拟时钟推进到原四分钟上限之外，仍完成三轮校验与补偿。资源观测回归覆盖七种设备配置，均确认不返回硬件档位建议。

多次滑动扩展前，降低模拟器配置后的冷启动实测自动启动已关机的所选实例、启动游戏、使用已有账号快速登录并导航至基建，极高档三轮全部通过，退出选人后宿舍一仍为 0/5。本轮约用时四分四十秒，超过已删除的总时限；保存的档位与时间参数保持不变。当时八个后端定向套件通过 183 项，六个前端套件通过 188 项。首次冷启动中，短暂加载帧被误识别为验证页面，因此在要求手动处理前增加重新取帧确认；真实验证与协议提示仍需手动处理。

多次滑动扩展仅使用离线验证：六个后端定向套件通过 166 项，两个受影响的前端套件通过 9 项，前端发布构建通过。回归先复现仅滑动一次的行为，再验证选择前滑动三次、后续手势使用当前页坐标、第三次滑动才到达的目标、每次选人独立准备，以及滑动之间的取消。按用户要求，本次扩展部署到本地后不再进行真实模拟器或电脑控制测试。

标准审查确认工作线程准入和退出所有权、锁顺序、可取消的状态轮询、有界单次 I/O、有界补偿，以及自动反馈和术语定义保持不变。需求审查确认从极高开始、连续三次通过、首次失败降档、低档失败不兜底推荐、准确名单核验、明确采用及设备配置或时间参数变化后的结果失效。当前审查范围内无可操作发现。本机结果仅对应当前 MuMu 实例与时间参数，其他设备需要各自实测。
