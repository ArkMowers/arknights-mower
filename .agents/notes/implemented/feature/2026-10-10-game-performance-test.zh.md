# 游戏内选人性能测试

[English](2026-10-10-game-performance-test.md)

## 决策

桌面端显式测试独占一次设备运行，使用宿舍一，不确认换人。从基建首页或该宿舍房间页开始。安全准备先确定首屏之外的两个目标；每轮实测使用候选档位的正式翻页、选人、重排和名单校验。连续三轮成功后推荐该档；首次失败立即降一档重新测试，低档失败则不给出建议。设备故障、导航或准备失败、取消直接中止，不作为性能降档依据。

测试使用总截止时间、可取消 I/O 和有界清理。正常结束或普通取消时取消暂选；退出程序或设备不可用可能阻止清理，并报告该情况。测试不确认进驻，不修改已保存档位、独立时间参数或自动反馈。明确采用后仅保存所选档位。设备或时间参数编辑使建议失效。连接资源读取在界面仅作为信息展示。

## 简化与记录归属

连接性能建议记录负责只读资源观测，本决策独立负责用户发起的输入测试。实现复用现有工作线程生命周期和设备运行边界，与正常排班共用选人和重排原语。不增加持久化测试缓存或第二个设备所有者。现有领域定义保持不变。

## 保证与验证

[INV-SCHED-45] 选人性能测试隔离约束有界逐级测试、明确采用和进驻及状态保留。离线验证覆盖成功、首次失败降档、全部档位失败、误选、未翻页、准备或设备故障、取消、清理、工作线程准入和过期界面结果。正式快速扫描与名单读取会拒绝日志中目标乌尔比安、斯卡蒂，实际猎蜂、斯卡蒂的误选。正常排班与显式测试共用重排坐标和时间策略。

八个后端定向套件通过 198 项用例，六个前端套件通过 188 项用例。前端发布构建、变更文件 Ruff、ESLint、格式与治理检查通过。治理检查保留两条历史归档引用提示。设备行为使用离线适配器，未运行真实模拟器测试。

标准审查确认工作线程准入和退出所有权、锁顺序、可取消的状态轮询、有界 I/O 和等待截止时间、有界补偿，以及自动反馈和术语定义保持不变。需求审查确认从极高开始、连续三次通过、首次失败降档、低档失败不兜底推荐、准确名单核验、明确采用及设备配置或时间参数变化后的结果失效。无可操作发现；模拟器具体识别和输入行为需由用户执行新增测试确认。
