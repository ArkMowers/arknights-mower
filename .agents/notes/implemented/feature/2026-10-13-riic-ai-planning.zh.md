# 基建 AI 排班

## 问题

Mower AI 缺少将已保存的干员练度、已有基建组合和设施驻员关联起来的工具。完整导入外部机制 skill 的目录和浏览器资源会重复 Mower 已维护的数据。

## 决策

[Arknights Mower AI 助手子系统说明](../../../../docs/subsystems/ai-assistant.md#riic-tools)规定三项只读工具的输入与检查边界：干员与组合概览、当前技能及嵌套术语查询、独立排班草案检查。现有表修改与局部主班共用校验工具；`plan_review` 指导纠错、局部优化及仅针对已拥有干员的基建养成建议。助手不从零生成排班，不为提高收益擅自换布局；`mower_tutorial` 读取当前自带教程的固定章节，明确来源与缺失范围。[实现](../../../../arknights_mower/agent/tools/riic.py) 使用已有阶段选择和 BOX 读取逻辑。用户明确给出的实际拥有和练度仅在本次调用优先于 BOX，并单独标注来源。养成目标保持为假设，不替代这些事实。

前端与 AI 共用一份 JSON 中的二十组组合定义。仅补充 v078 中缺失的三名干员，同名资源包记录优先。补充的角色标识在通用映射尚未收录时解析 BOX 拥有状态。现有词汇定义保持原义；此适配不修改排班执行逻辑或持久化结构。

## 考虑过的替代方案

复制完整外部目录及 HTML 浏览器保留了第二份 skill 分发包，但会重复干员与术语来源。精简解释指南配合三条缺失记录，使用现有 Mower 读取逻辑保留所需信息。

独立 skill 执行器或优化器增加运行时依赖，三项工具操作并不因此改善。现有聊天工具流程分发相同函数。用户撤回独立生成按钮和固定整表构造器，因为预设表无法覆盖不同 BOX 的选择。[已归档原型](../../archived/feature/2026-11-17-main-plan-generator.zh.md)保留比较依据。后续单布局生成指引仍让助手承担整表选择；用户进一步将用途收窄为现有表纠错与局部优化。完整表校验继续用于保留绑定并检查修改。

## 后果

试排展示拥有、练度、当前技能阶段、已配置工位和主班重复占岗错误，不保存或执行草案。旧的局部主班检查清空被修改房间的绑定，也不检查替班匹配，因此局部修改使用完整表副本；完整草案保留替班和多绑组，在隔离模型中运行原生结构校验。救急草案解析继承工位，新填写的干员排除正常排班已占用的姓名。副表触发、实际心情恢复、全局联动、电力和长期收益仍有明确限制。检查通过不表示长期轮休可行或 Scheduling Plan 最优。数值验证仍使用已有前端收益窗口，此扩展没有增加后端演算执行器。

固定外部指南覆盖 432 名干员。共享目录在本工作区原有 429 条记录上补充德·托莱多、克莱门莎和旅骨。资源更新提供同名记录后自动替代补充记录。

成功收益记录可整理为助手检查草稿，保留该次原始输入和结果，不读取当前编辑表替换。四个有长度上限的附件包含来源、参数、原表、工休与零心情驻岗、延期及有限事件，并明确省略范围。已有草稿和忙碌会话受到保护；用户通过现有附件与聊天流程自行发送，不新增接口，也不直接触发模型。历史来源字段缺失时保持未知。


检查同时区分配置、演算模型与调度实现问题。疑似代码异常通过固定本地 `code_diagnosis` 索引和实际源码片段分析，保留扫描位置、摘要、缺失状态及当前与历史版本差异，不通过改表掩盖实现缺陷。仅有模拟证据时先给复现与反馈草稿，相对小时不能变成实机日期或日志引用。实际设备事件沿用现有检查和证据区间；发送仍需用户明确同意、接口所需实际时间与有效引用，助手不自动修代码。

## 验证

[定向离线测试](../../../../arknights_mower/tests/riic_assistant_tests.py) 覆盖同槽升级、用户覆盖、缺失 BOX、拥有与练度错误、保留设施冲突、容量及两种模型分发流程。[共享资源测试](../../../../arknights_mower/tests/building_skills_tests.py) 覆盖补充角色的 BOX 身份和资源包同名记录优先。前端测试覆盖共享组合及聊天建议。真实模型推理与设备操作尚未测试。

外部 skill 格式检查通过。GameData、工具箱与 PRTS 检查为 current；Mower 回收站源码检查超时，总体时效状态保留 unknown。固定指南单独记录此限制，不将其等同于运行时目录覆盖。

机制查询另补分类、排班兼容、新干员、收益导出及来源时效主题；数值请求指引[前端收益窗口](../../../../docs/subsystems/plan-editor.md#income-export)，AI 不声称已代用户运行演算。[开发者 skill](../../../skills/mower-riic/SKILL.md)规定共享资源维护、固定源码摘要及定向验证入口。六项新增查询与枚举测试通过，保持当前解锁技能、原排班和敏感配置隔离。

完整表与执行链测试另覆盖真实原生组匹配、替班及充能对象的拥有和练度、救急继承与保留姓名排除、安全上下文快照，以及保存聊天调用链中较大 JSON 的完整传递。这些仍是离线检查，不表示已完成真实模型寻优或 AI 七天演算。

结构校验不证明优化有效。指南要求原表与候选同条件演算后再报告收益增益或排名，区分身份挂件与其自身技能解锁，并根据配置和事件追查零心情驻岗。工休比或缺少延期解除记录不能单独证明调度故障或期末死锁。

更新后的[提示检查](../../../../arknights_mower/tests/ai_prompt_contract_tests.py)通过十一项测试及十九项子测试，验证现有表范围、教程入口、假设练度及证据要求进入实际提示和注册知识工具。教程与检查草稿的行为使用[维护指南](../../../skills/mower-riic/references/maintenance.md#定向验证)列出的定向检查。文本及来源检查与行为结果分别报告；未验证真实模型推理、设备运行或实际收益提升。

四项现有表、收益诊断与代码诊断定向提示测试及八项子测试通过，验证源码索引入口及模拟材料、源码版本、实机时间与可发送反馈证据的区分；这些结果不验证某个具体疑似缺陷。
