# 检测时启动已选实例

[English](2026-09-29-instance-detection-start.md) | [中文](2026-09-29-instance-detection-start.zh.md)

## 契约

- **[INV-DEV-13] 检测启动目标**：检测仅启动只读检查确认为已停止、且预设支持启动控制的已选目标；目标有歧义或其他错误均不触发启动。
- MuMu Pro 启动和关闭先查询所选序号并核验保存的实例文件路径指纹，再发送单序号 `open` 或 `close` 命令。一个期限覆盖验证和命令执行。命令失败或结果不确定时不重放。
- 多个候选继续显示选择列表。选择候选或检测唯一发现的实例时允许本次启动检查。只读连接测试不执行生命周期操作。
- AVD、redroid、Genymotion 启动请求携带当前选定身份作为本次确认，不保存为后续定时任务授权。不支持启动控制的预设及手动 serial 配置保留手动启动提示。

MuMu Pro 检测在官方端口缺失时显式打开管理应用，此操作不发送 VM 启动命令。只读测试不打开管理应用。已选实例会话启动时，管理应用准备共用 Recovery Budget。

正常关闭仅关闭所选实例，保留管理器。管理器准备仅在 `mumutool port` 返回 `invalidPort` 时打开应用；管理工具可调用时不重启管理器。冷启动等待实例列表及所选 ADB 端口就绪。管理器报告实例操作错误时，提示用户在管理器中处理该实例。

## 验证

离线覆盖 MuMu Pro 目标核验、命令结果和会话启动，以及各设置预设的启动请求、检测行为、错误隔离和只读操作。[设备契约](../../../../docs/subsystems/device-control.md)规定长期接口。
