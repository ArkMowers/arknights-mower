# 配置备份包含 tmp 持久化数据

## 契约

[INV-CFG-01] 将配置与备份内的 tmp 持久化数据绑定到一次经过校验的导入和恢复快照。
[子系统契约](../../../../docs/subsystems/config-backup.md) 定义接口及失败保证。

## 实现

导出包含 SQLite 数据表、库存、仓库历史、报表、森空岛记录和加工站预设。
导入仅恢复备份内的 tmp 文件，缺失文件保留本机数据，兼容仅含 config 的既有备份。
导入清空保存的调度状态并保留本机访问设置。
SQLite 快照与恢复采用有时限的备份操作，包含 WAL 中已经提交的内容。

实现前的简化检查确认一个导出入口与两个压缩包读取入口，其中一个仅导入排班。
现有读取器统一负责路径校验；仅导入排班的入口忽略已经校验的 tmp 数据。
文件回滚循环覆盖两个目录，不引入独立的持久化子系统。

调度机制、配置模型和术语表定义均不变。术语表保持原样，任何修改仍需单独批准。

## 验证

定向离线测试覆盖数据表往返、WAL 快照、旧备份、访问设置保留、损坏数据库、
tmp 文件排除和失败回滚。治理与格式检查覆盖本决策三件套及其直接链接。
