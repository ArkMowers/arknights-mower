# LD 截图增强

[English](2026-09-29-ld-capture.md)

`ld_native` 为 Windows 雷电 9 和 14 选择 LD 截图增强。安装目录中的 `ldopengl64.dll` 只负责截图；触控独立选择 scrcpy 或 MaaTouch。

**[INV-DEV-05] 截图预设兼容性**：配置更新拒绝不兼容的厂商截图预设，截图入口还验证主机类型；界面切换预设时，在草稿中清除不兼容的截图选择及其耦合触控选择。

**[INV-DEV-06] LD 截图绑定**：LD 截图增强验证所选 ADB 端点与所选实例的对应关系，仅在进程身份及 1920×1080 尺寸保持不变时接受画面。

独立持有的子进程隔离 DLL，复用截图对象，将倒置 BGR 转换为 RGB，并在正常退出时释放对象。调用方限制请求时间，清理时只终止自己持有的工作进程。原生调用失败由现有截图错误边界报告，不会选择其他实例或截图后端。

草稿中存在尚未确认的其他预设时，界面延后保存截图和触控选择。旧配置保持可读，不兼容选择须在保存或截图前修正。ADB 服务共享管理保持不变。

Windows MuMu 预设显示为 **MuMu 12**，标识保持为 `windows.mumu12`。

接口依据：[MAA LD 截图实现](https://github.com/MaaAssistantArknights/MaaAssistantArknights/blob/dev-v2/src/MaaCore/Controller/LDExtras.cpp)及[厂商接口声明](https://github.com/MaaXYZ/EmulatorExtras/blob/54d3a3ad448f0541df3759ae91b571a6762daaf1/LD/dnopengl/dnopengl.h)。

离线测试覆盖配置拒绝、界面选择、RGB 方向、实例身份、截止时间和清理，不包含运行模拟器验证。

## 定向实机验证

经用户授权的只读截图在 Windows 雷电 9.5.30.1 明日方舟专版通过，目标为实例 1000，尺寸为 1920×1080。六帧样本的首次调用耗时 3.20 秒，后续五次调用中位数为 131 毫秒；三次 ADB 截图的中位数为 454 毫秒。静态画面与 ADB 截图一致，关闭会话后没有遗留的自有工作进程。此样本验证该版本的已安装 DLL 与截图链路。

同样经用户授权的检查在 Windows 雷电 14.0.29.0 的实例 0 通过，使用现有 `windows.ldplayer14` 截图链路，无需修改生产代码。六次增强截图均输出 1920×1080 RGB 画面：首次调用耗时 2.97 秒，后续五次调用中位数为 114 毫秒；三次 ADB 截图中位数为 244 毫秒。保存的静态游戏画面逐像素一致。会话清理耗时 84 毫秒，没有遗留的自有工作进程。检查只读取画面，不发送游戏输入或更改持久化配置。上述耗时仅描述本次样本。

## 规范检查

通过：原生调用位于独立持有的工作进程中，实例观测不持久化，管理器调用共享截图截止时间，清理仅涉及自己持有的资源。ADB 服务共享管理和 MuMu 截图触控配对继续生效。经用户批准的标准画面帧术语更新包含 LD 截图增强。

## 功能检查

通过：LD 截图增强接入预检和运行时，不兼容的界面与 API 选择被拒绝。切换预设及跨产品选择检测结果均清除不兼容草稿。尚未确认的预设对应的后端编辑保留在草稿中。离线测试覆盖这些边界；上述定向实机验证确认已安装雷电 9 明日方舟专版和雷电 14 的截图和清理正常。
