# Log Item Artwork

`drone.png` is the unmodified in-game item artwork linked from the [PRTS drone page](https://prts.wiki/w/%E6%97%A0%E4%BA%BA%E6%9C%BA). [sources.json](sources.json) records the download URL and SHA-256. The artwork belongs to Hypergryph; see the [PRTS copyright notice](https://prts.wiki/w/PRTS:%E7%89%88%E6%9D%83).

Other log item icons reuse the existing `ui/public/depot/` assets. Product colors come from `BASE_PRODUCT_COLORS`, shared with the base report, and order classifications use `ORDER_COLORS`. A named operator's order uses that operator's existing portrait rather than a currency icon.
