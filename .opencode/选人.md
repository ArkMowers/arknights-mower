# AgentSelectionFSM — 选人状态机设计

> 替代旧 `solvers/base_schedule.py:choose_agent()` (2711行，~250行 while+flag)

## 输入/输出

- **输入**: `agents: list[str]` (1-5个干员名, "Free" 表示任意空位), `room: str`, `fast_mode: bool`
- **输出**: 干员选入基建设施, tap 操作序列

## 状态图

```
PREPROCESS    去重、处理 Free 位、心情检查
    ↓
FAST_CLEAR    快速模式: 清除错误位置的干员 (tap position[0-4])
    ↓
MAIN_PREPARE  设置职业筛选 (profession_filter) + 排序方式 (arrange_order)
    ↓       ↰
SCAN_SELECT   扫描当前屏幕 → 选中目标干员 (tap)
    ↓       │  found? ──→ SWIPE_NEXT 滑下一页
    ↓       │  not found + swipe < max → SWIPE_NEXT
    ↓       │  not found + swipe == max → ERROR
    ↓
FREE_ASSIGN   补齐 Free 空位 (心情排序 → 选空闲干员)
    ↓
FINAL_SORT    技能排序 + 左滑归位
    ↓
VERIFY        验证选中人数 = agents 人数
    ↓
DONE
```

## 各状态处理

### 1. PREPROCESS
- 去重: 同名干员替换为 "Free"
- 宿舍检查: 满心情+非宿舍房 → 释放休息位
- Free保活: `free_room` 模式 → 保留未满心情的当前干员

### 2. FAST_CLEAR
- 仅在 `fast_mode=True` 且房间非空时执行
- 获取 `current_room` 列表 (forward fill 空位)
- 对比 `agents`: 位置不匹配的干员 → tap(position[i]) 移除
- 移除不在 agents 中的干员

### 3. MAIN_PREPARE
- 根据第一个干员确定排序: 宿舍 → 心情升序, 生产 → 技能优先
- 职业筛选: 宿舍/非生产 → 按干员职业筛选, 阿米娅 → ALL
- 左滑归位 (swipe_right → 0)

### 4. SCAN_SELECT (循环)
- `scan_agent(agents)` → 识别屏幕上的干员名
- 匹配的干员 → tap 选中 → 更新 `selected` 列表
- 全部找到 → FREE_ASSIGN (有Free时) 或 FINAL_SORT
- 未找到 → 右滑一页 → SWIPE_NEXT → 回到 SCAN_SELECT
- 到底了 (swipe > max_swipe 或 回到 first_name) → ERROR

### 5. FREE_ASSIGN
- 仅在 agents 含 "Free" 时进入
- 职业筛选 → ALL
- 排序 → 心情升序
- `get_free_list()` → 可选空闲干员列表
- 逐个 scan 选中, 直到 free_num == 0

### 6. FINAL_SORT
- 左滑归位
- 排序 → 技能
- 按 agents 顺序逐个 tap 确认位置

### 7. VERIFY
- `selected` 长度 == agents 过滤后长度 → DONE
- 否则 → throw error
