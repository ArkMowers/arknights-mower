# Mower 一条龙入门说明 { #preface }

本说明介绍 Mower 的当前功能与界面，更新时间：2026-10-09。实际软件版本和可用操作以你所用平台的页面提示为准。

**先完成设备连接和排班核对，再逐项打开需要的自动化。**软件更新、资源更新、刷理智周计划和大型任务各有自己的入口与开关。

1. [安装或更新](install.md#download-update)：选择源码部署或官方发布包，已有程序在“软件更新”检查版本。
2. [绑定设备](device.md#device-connection)：选择平台预设，检测并选定目标实例，核对连接状态。
3. [导入或编辑排班](schedule.md#scheduling)：核对设施、主班、绑组、替班、宿舍和副表，完成校验。
4. [选择基建与日常任务](mower-settings.md#Mower-settings)：按需要开启线索、跑单、邮件和签到等功能。
5. [配置作战](tasks.md#sanity-plan)：周计划选择 MAA 或 Mower 执行方式；大型任务独立设置。
6. [配置养成与专精](growth.md#growth-workshop)：先同步练度和库存，再核对目标、路线与自动合成。
7. [启动并观察](diagnostics.md#diagnostics-ai)：先确认一轮换班和所选任务正常，出现异常查看对应日志或归档。
8. [导出备份](backup.md#configuration-backup)：保存当前实例的配置及持久化数据，迁移前再导出一次。

问题与建议可查阅 [Mower 反馈表](https://docs.qq.com/sheet/DUEJ6UWN5VFVRU0dG?tab=BB08J2)。

文档站支持浅色、暗色和跟随系统三种显示方式，可使用页面顶部的主题按钮切换。
