# 日志、排错与 AI 助手 { #diagnostics-ai }

## 先看具体证据 { #error-archives }

运行日志查看任务、时间、设施、干员和异常堆栈。报错归档保留对应现场；选择具体归档后可使用 AI 分析。连接状态、更新日志和排班任务日志分别对应不同问题，单独一条 ERROR 不能证明唯一根因。

清理数据先导出备份，再在运行日志页面的“数据库管理”选择确实需要删除的类别。心情记录、专精计划、专精路线、库存和运行缓存彼此独立，不全选、不直接删 data.db。

## DeepSeek、本地与在线模型 { #local-ai-assistant }

1. 在 Mower 设置 → AI 助手与模型服务选择 DeepSeek、本地 OpenAI 兼容接口或在线模型/中转商。选择 DeepSeek 后，在“DeepSeek 模型”选择 Flash / Pro 预设，或输入官方模型 ID 后回车，并填写 DeepSeek 密钥。
2. 自定义接口填实际模型ID与接口地址。本地需兼容 OpenAI Chat Completions，通常可不填密钥；在线接口要求 HTTPS 和对应密钥。
3. 聊天工具调用需要服务及模型支持工具调用。助手可查 FAQ、日志及数据库、分析漏单与错误、管理专精计划及按明确要求发送反馈。
4. 核对工具实际返回。AI 建议中的推测不等于已证实的根因，也不代表排班已自动修改。不要发送密码、API密钥或访问令牌。

漏单分析先选择具体记录或提供完整本地时间，再结合任务时间线；漏单报警的时间不一定是原任务时间。
