# 专精推荐模块 (Mastery Recommendation)

## 📖 功能总览

- **数据深度集成**：支持从 **森空岛** 读取干员练度数据，并结合 **仓库读取** 功能，自动计算干员专精所需材料及缺失情况。
- **颗粒度计划定义**：支持以 **单个技能** 为最小单位定义专精计划，灵活规划资源。
- **一键自动合成**：点击“自动合成配置”按钮，系统将自动安排以下资源的合成任务：
    - **T5 (金色) 材料**
    - **T4 (紫色) 材料**
    - **技巧概要**（技能书）
- **缺失汇总**：自动汇总所有缺少的 **T3 级材料**，方便用户一目了然地查看并针对性刷取。

---

## ⚙️ 合成干员设置指南

设置项位于页面 **右上角**，按以下顺序从左到右排序：

| 合成目标 | 对应位置 | 默认干员 | 说明 |
| :--- | :--- | :--- | :--- |
| **T5 材料** | 左侧选择框 | **年** | 支持自定义更改 |
| **技巧概要** | 右侧选择框 | **司霆惊蛰** | 支持自定义更改 |
| **T4 材料** | 逻辑内置 | **九色鹿** | 仅支持并推荐使用。若无该干员，请在 mower 合成设置中手动更改。 |

---

## 🛠️ 使用流程

1. **同步数据**：读取森空岛练度及仓库库存。
2. **定义计划**：在列表中勾选需要专精的技能。
3. **查看缺口**：在汇总区确认缺失的 T3 材料。
4. **启动合成**：确认右上角干员配置后，点击“自动合成配置”即可完成 mower 的合成逻辑部署。
