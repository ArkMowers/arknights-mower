# 理智算法介绍

理智算法用来比较排班收益：把基建一天产出的东西都换算成理智价值，再减去消耗材料的价值。

**日均收益 = 一天的产出价值 − 一天的消耗价值**

每种资源的价值都按「数量 × 单价」计算，再把各项加起来。单价的单位是「理智/个」，例如 1000 龙门币的价值为 `1000 × 龙门币单价`。

这样，经验、龙门币、材料、合成玉，以及办公室和会客室的收益，就能放在一起比较。数值越高，表示按你设置的价格计算，这套排班的收益越高。

## 怎么使用

在排班表中打开「计算收益」，选择「理智算法」。首次使用和恢复默认时会选中它。这个算法只用于计算收益，基建报表仍默认使用 0.23456 算法。

可以先使用默认价格，再按自己的需求调整。比较两套排班时，要使用相同的价格、练度、设施等级、初始库存和演算时长；随机抽单时也应使用相同的随机种子。

## 材料价格从哪里来

**整份内置材料价值表由 @32767 提供。**材料按 SS 活动估值，合成考虑九色鹿、蚀清和年的技能。合成玉也直接使用表中价格，内置值为 **0.9225 理智/个**。

你可以导入或修改价格，让它更符合自己的需求。这份表不会自动跟随新活动更新，修改某项材料价格也不会自动重算整张表。

## 各设施怎么算

| 设施 | 计算方式 |
| :--- | :--- |
| 制造站、贸易站 | 计算经验、龙门币、赤金和合成玉等产出，扣除生产和交货消耗的材料 |
| 回收站 | 按生产次数，计算普通掉落和积分奖励的平均价值 |
| 办公室 | 估算刷新标签能多获得多少黄票、绿票，再换算成理智 |
| 会客室 | 把线索和持续交流带来的信用，按你设置的信用价值计算 |

赤金和源石碎片只计算生产与消耗的差额，避免同一份东西在制造和出售时重复计入收益。初始库存不算本次产出。

导出的收益图在右侧分别列出回收站、会客室和办公室的日均理智收益。会客室包含线索赠送与持续交流；这三项已经计入总收益，不需要再加一次。

回收站和办公室使用平均收益，不能预测某一次掉落或公招结果。目前也没有扣除投入回收站用于提效的材料消耗。

## 哪些设置需要按自己情况调整

**办公室潜能预设**有三种：

- **默认**：四星、五星、六星分别按 1、5、10 黄票估算。
- **当前森空岛数据估算**：根据本地保存的干员拥有情况和潜能估算，需要提前更新森空岛数据。
- **满潜**：四星、五星、六星分别按 1、13、25 黄票估算，包含多余信物兑换。

绿票也会计入。刷新收益参考[一图流公招标签统计](https://ark.yituliu.cn/survey/maarecruitdata)，假设只刷新没有保底的标签；森空岛潜能也只是近似依据，因此办公室收益是估算值。

```text
办公室日均收益 = 每天刷新次数 ×（每次新增黄票 × 黄票单价 + 每次新增绿票 × 绿票单价）
```

这里的「新增」是相对于不刷新、按三星招募结果计算，多得到的平均数量。

**黄票价值**可以选择按「258 黄票换 38 抽」或「兑换六星皇家信物」估值。按自己实际会用到的兑换方式选择，不会因为持有量超过 258 自动切换。黄票已经没有用途时，可以把价值设为 **0**。绿票按兑换合成玉估值，不计商店前置兑换；黄票、绿票的单价都可以单独修改。

| 兑换方式 | 每张凭证的理智价值 |
| :--- | :--- |
| 黄票换抽卡券 | 38 × 600 × 合成玉单价 ÷ 258 |
| 黄票换六星皇家信物 | 720 × 采购凭证单价 ÷ 135 |
| 绿票换合成玉 | 30 × 合成玉单价 ÷ 50 |

其中每抽按 600 合成玉计算；信物按同一件的采购凭证价格与黄票价格换算。

**信用价值**默认参考信用商店的购物性价比门槛，也可以手动修改。会客室按自产线索全部赠送、好友持续补齐线索并连续交流估算：每条自产线索计 40 信用，已建会客室每天另计 210 交流信用。

信用用不完时，可以设置「每日有效额度」，只给仍然用得上的部分计价。这个额度应扣除访问好友、信息板等其他信用收入已经满足的需求。例如每天产生 370 信用，但只有 250 仍有用，每信用值 0.2 理智，就计入 **250 × 0.2 = 50 理智/天**。额度留空表示不限制，填 0 表示不计信用收益；它不会改变实际购物或信息板领取方式。

```text
每天产生的信用 = 每天自产线索数 × 40 + 210（已建会客室）
会客室日均收益 = 每天产生的信用与每日有效额度中的较小值 × 信用单价
```

## 搓玉为什么可能是负收益

搓玉按同一份价格表计算：获得合成玉是收入，消耗固源岩、装置和龙门币是成本。

例如，按内置价格，消耗 4 个固源岩和 3200 龙门币，制成碎片后卖出，得到 20 合成玉：

- 合成玉价值约 **18.45 理智**。
- 消耗材料价值约 **24.95 理智**。
- 净收益约 **−6.50 理智**。

负数表示消耗材料的价值高于得到的合成玉价值。算法保留这个结果；你仍然获得了合成玉，只是它与刷材料的需求取舍不同。

尚未卖出的源石碎片也会计价，默认参考赤金制造与出售的价值比例，也可以手动设置。碎片全部卖出时，中间价格会抵消；生产和出售不平衡时，要同时看碎片净数量。

```text
碎片净数量 = 生产碎片数 − 出售消耗的碎片数
搓玉净收益 = 合成玉产量 × 合成玉单价 + 碎片净数量 × 碎片单价 − 制造耗材价值
```

结果中的搓玉明细会分别列出制造、贸易和合计收益，已经包含在基建总收益里，不需要再加一次。

## 怎么看结果

- **显示「部分」收益**：有产出或消耗缺少价格，先检查列出的未估值项目。
- **某项资源对你没有用**：把价格填为 0。清空手动覆盖通常表示恢复自动估值，并不表示价值为 0。
- **改价后查看旧结果**：旧结果仍使用当时的价格，需要重新演算才能看到新价格下的收益。
- **修改材料表**：价格也供回收站统计、养成统计和信用购物使用，修改会影响这些功能。
