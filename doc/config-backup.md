# 配置导出与导入

入口位于 **Mower 设置页面下方 → 配置导出与导入**，在「进程操作」板块上方。

点击「导出全部配置」会先保存当前编辑内容，再下载一个带格式版本和导出时间的 JSON 文件。
备份包含当前实例的所有 Mower / MAA 设置（包括界面未显示的设置）、主排班与备用排班、
全部周计划及活动回退和库存选关规则、专精计划和训练员路线设置、加工站手动与自动配置、
保全派驻作业、窗口设置、页面偏好，以及共享网络代理、软件更新设置和森空岛设备信息。
其中专精计划和训练员配置从数据库单独导出。

导入步骤：

1. 停止 Mower，等待更新任务结束。
2. 点击「导入配置」，选择此前导出的完整配置 JSON 文件（最大 16 MB）。
3. 确认覆盖当前配置。服务端先校验完整备份，再把现有配置保存到当前实例数据目录下的
   `config-backups/before-import-时间-标识.json`，随后写入新配置；写入失败会回滚。
4. 成功提示会显示导入前备份路径。点击「刷新页面」加载新配置，此次刷新不会自动启动任务。
   窗口、服务端口等启动设置需要重启 Mower 才会生效。

导入会覆盖当前实例配置及共享网络设置；其他实例的配置、程序文件、日志、统计记录和仓库识别数据不在备份内。
旧调度缓存会清空，下次启动按导入后的计划重新生成任务。迁移到其他电脑后，请检查 MAA、ADB 和模拟器路径。
如需撤销导入，可选择上述自动生成的备份文件再次导入。

备份会完整保留账号、密码、访问令牌和 API 密钥，请妥善保管，不要公开分享。
仅含排班的旧 JSON 文件仍应通过排班页面导入，不适用于完整配置导入入口。
