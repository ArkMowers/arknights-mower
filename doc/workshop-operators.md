# 加工站干员设置

打开设置时读取已同步的 BOX，按干员实际精英阶段、等级及技能升级链筛选已解锁的加工站技能。尚未改过的出厂名单自动替换为个人名单；已有自选名单保留，点击「恢复默认」可重新按当前 BOX 填写。设置保持多选，不增加「计算最优」按钮，也不自动触发森空岛同步。缺少 BOX 或资源规则时提示原因并保留现有设置。

针对每种配方比较固定副产品概率加成，保留全部并列最高者，再合并为非 T5、T5、技巧概要三类名单。材料系列、指定材料及配方原始消耗条件分别匹配，例如装置系列、包含酮阵列的酮凝集系列、仅炽合金块的号角技能。按 BOX 读取已解锁版本，同组技能升级不重复叠加。宿舍、情报储备等动态加成不预设已满足；只有心情消耗减免的技能不作为概率加成。设置内可展开查看推荐材料分工。

年的高概率加成保留给 T5：自动推荐和生成合成配置时，只将年用于 T5 材料。非 T5 材料从其他可用干员中比较加成；没有其他候选时留空，不让年回填。旧名单即使在非 T5 或技巧概要分类选择了年，自动生成配置时也会跳过这些分配。

自动填写的三个分类互斥：按 T5、技巧概要、非 T5 的顺序，在每个分类内比较剩余候选的材料加成，保留并列者和专属干员；选入前一分类的干员不再参与后续分类。同一分类仍可填写多位干员。

主排班及全部备用排班中的主力和替换干员，只要出现在宿舍、加工站以外的任何设施就排除，包括训练室、中枢和活动室。仅在宿舍或加工站出现时允许参与；同时在其他设施出现时仍排除。生成自动合成配置时重新检查最新排班，旧资源或未读取 BOX 时也执行这项过滤；手动下拉保留全部干员，已选冲突干员在设置中提示。

九色鹿只需持有，不要求精二，仍受同样的排班过滤。界面保留原有垫刀材料提示，没有新增九色鹿说明。实际使用沿用已有垫刀流程，碳素、碳素组、家具零件_碳素组只分配给九色鹿。

生成合成配置时按所选干员对每种材料的加成分配任务，并列者均保留，九色鹿额外保留非 T5 材料。用户可手动增删任意干员。多个分类选择同一干员时合并其任务，避免执行器只读取第一条配置而漏掉其他分类；材料库存上下限保持原计算。旧资源或未读取 BOX 时沿用手动名单的原材料分配方式。

添加训练计划时，若被训练干员出现在三个加工分类的已选名单或已启用的合成配置中，提示专精可能影响合成，仍允许添加。单项添加、批量添加、计划草稿和专精确认弹窗共用此检查。仅作为推荐展示、尚未选中的干员不触发警告；已停用且未在分类名单中选择的配置也不触发。占用名单使用响应式集合，与空闲／非空闲过滤共用，变更选人后自动更新。

规则由 `workshop_rules.compile_workshop_data` 在资源生成时写入 `skill_data.json.workshop`（version=1）。推荐仅在打开设置、恢复默认或生成加工配置时读取缓存数据，不增加游戏扫描或调度循环开销。本次没有修改加工实机操作或增加专精心情识别。
