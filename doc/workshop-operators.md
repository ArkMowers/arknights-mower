# 加工站干员设置

打开设置时读取已同步的 BOX，按干员实际精英阶段、等级及技能升级链筛选已解锁的加工站技能。尚未改过的出厂名单自动替换为个人名单；已有自选名单保留。「恢复默认」改为「一键设置」，旁边可填写副产品概率加成下限，默认 80%，以 `workshop_min_bonus` 保存到用户配置。点击后填入所有达到该下限的可用干员。设置保持多选。点击一键设置时先调用现有森空岛干员同步接口，等待新 BOX 写入后再读取加工站候选；同步失败、未配置账号、未匹配到所选服务器或缺少资源规则时提示原因并保留现有名单，不使用旧 BOX 继续覆盖。仅打开设置仍读取已有 BOX。

针对每种配方计算固定副产品概率加成，保留全部达到所设下限的干员，不只保留最高者。材料系列、指定材料及配方原始消耗条件分别匹配；通用加成与已解锁的条件加成相加，同组技能升级不重复叠加。宿舍、情报储备等动态加成不预设已满足。心情消耗减免不计入概率；对于缇缇这种同时具有 80% 通用加成和指定配方减耗的干员，按减耗适用范围安排分工。设置内可展开查看推荐材料分工，专属干员完整列出所分配的材料。展示名单独立于一键设置的自定义下限：仅展示九色鹿、已解锁 80% 技能的蚀清、材料加成至少 90% 或技巧概要加成至少 80% 的可用干员，特殊材料适用同样的展示门槛。80% 材料干员仍可按一键设置阈值填入，只是不出现在这份展示名单中。

当前资源中的固定特殊加成如下；所有干员仍需满足持有、技能解锁和排班条件。百分比均为副产品概率加成，而非最终出货概率。

| 干员 | 解锁阶段 | 匹配范围 | 加成 |
| --- | --- | --- | --- |
| 贾维 | 精二 | 装置系列 | 90% |
| 奥斯塔 | 精二 | 聚酸酯系列 | 90% |
| 泥岩、谬因 | 精二 | 源岩系列 | 90% |
| 熔泉 | 精二 | 异铁系列 | 90% |
| 号角 | 精二 | 仅炽合金块 | 100% |
| 维荻 | 精一 | 酮凝集系列（含酮阵列） | 80% |
| 特克诺 | 精二 | 晶体系列 | 80% |
| 折桠 | 精二 | 仅异铁组 | 90% |
| 休谟斯 | 精一 | 原始心情消耗为 2 的精英材料 | 50% + 40% = 90% |
| 缇缇 | 精二 | T5，原始消耗为 8 的配方减为 4 | 80% |

休谟斯匹配全新装置、酮凝集组、异铁组、聚酸酯组、糖组、固源岩组；原始消耗为 1、4、8 的配方和技巧概要不在其自动分工内。范围判断使用配方原始消耗，不使用被技能减免后的消耗。

年的高概率加成保留给 T5：自动推荐和生成合成配置时，只将年用于 T5 材料。非 T5 材料从其他可用干员中比较加成；没有其他候选时留空，不让年回填。旧名单即使在非 T5 或技巧概要分类选择了年，自动生成配置时也会跳过这些分配。

80% 加成干员允许跨分类：空爆可同时填入非 T5 和 T5，凯尔希·思衡托可填入三类，特克诺可同时负责晶体电路与晶体电子单元。材料条件仍要匹配，所以缇缇只分配 T5。其他干员继续按 T5、技巧概要、非 T5 的顺序分配到一个分类；每个分类均可填写多位干员。

九色鹿、蚀清的精英材料合成仅限 T4，莱伊排除 T4；T4 以配方原始消耗为 4 判断，不受减耗技能影响。这些范围同时约束自动名单、配置生成、已有配置的任务派发和实际加工入口，旧的错误分类选择和已排队任务也不能绕过。读取时过滤副本，不改写用户保存的库存上下限。

推荐名单、生成的配置及实际任务派发中，九色鹿第一、蚀清第二，其余按副产品概率加成降序排列。同加成时优先有已解锁宿舍技能的干员，无论宿舍技能是自回还是帮助他人；仍未解锁的技能不参与优先级。当前 80% 材料干员中优先蜜莓，T5 其次为缇缇；80% 技巧概要干员中子月、赫拉格优先于无宿舍技能的干员。宿舍优先级不超过更高概率加成。现有加工站心情门槛不变，优先干员不满足原有使用条件时可由后续候选执行。派发会重新排序已有配置，不要求用户重建名单才能生效。

主排班及全部备用排班中的主力和替换干员，只要出现在宿舍、加工站以外的任何设施就排除，包括训练室、中枢和活动室。仅在宿舍或加工站出现时允许参与；同时在其他设施出现时仍排除。生成自动合成配置时重新检查最新排班，旧资源或未读取 BOX 时也执行这项过滤；手动下拉保留全部干员，已选冲突干员在设置中提示。

九色鹿只需持有，不要求精二，仍受同样的排班过滤。推荐条目仅显示名字，界面保留原有垫刀材料提示。实际使用沿用已有垫刀流程，碳素、碳素组、家具零件_碳素组只分配给九色鹿。

生成合成配置时按所选干员对每种材料的加成分配任务，达到所设下限的干员和匹配的专属干员均保留，手动选择的较低加成干员沿用并列最高的分配方式，九色鹿、蚀清作为 T4 优先候选保留。专属干员只分配符合其条件的材料；没有其他候选、全员对某材料均为零加成或缺少 BOX／外置资源规则时，也不会把无关材料分配给已知专属干员。用户可手动增删任意干员。多个分类选择同一干员时合并其任务，避免执行器只读取第一条配置而漏掉其他分类。

若某材料的专属概率加成达到该材料候选中的最高值，则普通候选仅保留对应专属干员，同种材料的多个专属干员可共同保留，并按加成排序。九色鹿、蚀清是明确的 T4 优先例外，仍可先于对应材料专属干员使用；其他通用干员继续排除。例如异铁组可分配给熔泉、折桠、休谟斯，不再分配给通用干员。若通用干员加成更高，则保留其优先权：年 100% 仍优先于特克诺 80% 合成晶体电子单元。缇缇只有减耗条件，不能因此独占 T5；蜜莓 80% 在她之前。专属干员未选入、未拥有、技能未解锁或被排班占用时，不触发材料独占。

除原有 T4、T5、技巧概要配置外，额外为已拥有、已解锁且未被排班占用的所选专属干员补入对应低阶材料，避免折桠、休谟斯选入后没有任务。无训练计划时沿用默认库存下限／上限 20；有计划时计算低阶材料直接需求及缺少 T4 的配方需求，按配方实际数量累计并扣除已有 T4，库存上限为所需数量。补入的低阶任务不分配给通用干员或九色鹿；缺少 BOX／规则时不新增低阶任务。其他材料库存上下限保持原计算。

添加训练计划时，若被训练干员出现在三个加工分类的已选名单或已启用的合成配置中，提示专精可能影响合成，仍允许添加。单项添加、批量添加、计划草稿和专精确认弹窗共用此检查。仅作为推荐展示、尚未选中的干员不触发警告；已停用且未在分类名单中选择的配置也不触发。占用名单使用响应式集合，与空闲／非空闲过滤共用，变更选人后自动更新。

规则由 `workshop_rules.compile_workshop_data` 在资源生成时写入 `skill_data.json.workshop`（version=1）。宿舍技能以 `kind=dormitory` 保留在原技能升级链中，按 BOX 精英阶段和等级解锁；不将只有宿舍技能的干员加入加工站候选。兼容字段 `recipe_ingredients` 直接从游戏基建表保存 39 种精英材料配方的原料数量；计划需求优先使用该字段，旧资源回退到已有 `composite`，不依赖第三方配方表是否随生成环境提供。推荐仅在打开设置、一键设置或生成加工配置时读取缓存数据；一键设置额外同步一次森空岛数据，加载期间禁用按钮以避免重复请求。实际加工入口仅增加材料范围过滤，不增加游戏扫描或专精心情识别。
