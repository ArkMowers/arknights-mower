# 排班干员持有检查

点击「验证排班」或启动 Mower 时，排班验证会检查主表和副表中的主力、替班干员，以及副表任务中的干员。空位、`Current` 和 `Free` 不参与检查。

如果本地已有森空岛干员名单，排班中的干员未出现在名单里时，Mower 会尝试重新同步。同步成功后仍未出现的干员会列在错误提示中；请确认账号持有情况并修改排班。同步不可用时，旧缓存不足以证明账号没有该干员，因此跳过持有检查，继续原有排班验证。

仅做过仓库扫描、尚未同步干员数据时，程序生成的 `cultivate.json` 只有物品信息，持有检查会跳过。若已同步的干员数据损坏，请到「养成规划」页面手动点击「刷新」，同步后重新验证排班；若提示资源中缺少排班干员的森空岛 ID，请更新资源包。

训练室第二个位置是训练位。该检查覆盖主表、副表的训练位主力、所有组绑定的替班及副表换人任务，协助位不参与这两项技能检查。

1. 基础技能不足七级时，先在游戏中升级至七级；所有技能均已专三时，更换训练位干员。
2. 到「养成规划」页面手动点击「刷新」，同步最新干员数据。技能字段缺失时也使用这一入口。
3. 回到排班页面重新验证；仍有错误时，按提示的主表或副表、训练位干员检查替班与任务。更新资源不能代替干员练度同步。

发现训练条件不符时会尝试同步一次；同步失败仍报告缓存中已知的训练条件错误。尚无干员名单时保留原有验证行为，跳过检查不表示已满足开训条件。持有检查确认账号未持有干员时，获取或替换干员后也需在「养成规划」刷新，再验证排班。
