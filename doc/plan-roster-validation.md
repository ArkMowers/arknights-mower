# 排班干员持有检查

点击「验证排班」或启动 Mower 时，排班验证会检查主表和副表中的主力、替班干员，以及副表任务中的干员。空位、`Current` 和 `Free` 不参与检查。

如果本地已有森空岛干员名单，排班中的干员未出现在名单里时，Mower 会尝试重新同步。同步成功后仍未出现的干员会列在错误提示中；请确认账号持有情况并修改排班。同步不可用时，旧缓存不足以证明账号没有该干员，因此跳过持有检查，继续原有排班验证。

仅做过仓库扫描、尚未同步干员数据时，程序生成的 `cultivate.json` 只有物品信息，持有检查会跳过。若已同步的干员数据损坏，请重新同步干员数据；若提示资源中缺少排班干员的森空岛 ID，请更新资源包。

训练位提示基础技能不足七级或所有技能均已专三时，请升级并同步干员数据，或更换训练位干员。该检查覆盖主表、副表的训练位主力、所有组绑定的替班及副表换人任务，协助位不参与检查。发现训练条件不符时会尝试同步一次；同步失败仍报告缓存中已知的训练条件错误。技能字段缺失时提示重新同步；尚无干员名单时保留原有验证行为。
