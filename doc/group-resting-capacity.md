# 混合优先级工作组的下班与待命

延续 #942 的床位分配修复，区分普通替班与排班中设为低优的主力成员。

以深海组为例：歌蕾蒂娅为高优，其余六名工作成员为低优。达到下班条件、整组替班均可用时，先给必须恢复心情的成员安排床位，再为可待命的低优成员安排剩余床位：

| 剩余床位情况 | 下班结果 |
| --- | --- |
| 一个空位，其余由普通替班占用 | 深海主力可以接管普通替班床位，低优仍保留其选床偏好 |
| 一个空位，其余由其他尚未休息完的主力占用 | 歌蕾蒂娅入宿舍，其余六人撤下待命，其他主力继续休息 |
| 存在部分可用床位 | 歌蕾蒂娅优先获得床位，低优成员有床则休息，其余待命 |
| 没有能分给必需休息成员的床位 | 不生成整组下班安排，不留下部分床位分配 |

待命成员不恢复心情，随同组高优成员的回班任务一起返回原工作岗位。待命期间不会因为后来出现空床就额外生成插入宿舍的任务。

只有组内存在需要恢复心情、能实际入宿舍的高优主力时，普通低优主力才可以待命。没有这样的高优成员、全组均为低优，或高优已满心情时，仍要求完整分床。用尽、回满、加工干员不使用此待命规则；零心情工作的干员沿用原有逻辑。整组替班不足时仍不下班。

纠错根据实际阵容识别待命：低优成员已离岗、其原岗位有配置内的有效替班、同组高优主力正在轮休床位休息。符合时不因离岗或心情记录陈旧而叫回；待命成员也不参与平均工作心情及在岗干员耗尽时间预测。识别不需要额外状态文件，重启后读取到阵容即可恢复。

如果原岗位缺少有效替班，仍执行现有纠错；能补替班则补替班，不能补时保留原有异常恢复流程。并非禁止所有纠错，也不掩盖实际错位或已失去组内休息依据的离岗。

本规则由现有工作组和低优配置生效，不要求宿舍干员绑组，不修改排班文件。普通替班之间不能互踢，尚未休息完的其他主力（包括低优主力）仍受保护。
