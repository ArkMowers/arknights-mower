# 设备性能适配

「Mower 设置」提供自动、极高、高、中、低五种性能模式，其中极高档的配置值为 `xhigh`。旧配置中的 `ultra` 会迁移为 `xhigh`。Android 默认自动，其他平台默认高性能；Android 不提供极高和高性能。自动档只在高、中、低之间调节，不会启用极高性能。

自动档观察选人操作后的画面反馈，包括排序箭头、职业筛选和翻页后的名单变化。一次操作从第一次观察到反馈为 0 帧延迟；若要继续观察，则记录额外观察帧数的指数移动平均。前 4 次反馈沿用平台默认档，之后用不同的升降阈值避免临界值附近反复切换。截图耗时仅用于诊断，不参与档位判断。

两次选人相关失败之间没有成功完成选人流程时，自动档降低一级；普通进房、倒计时等异常不计入。降档后需要连续三次完成选人流程，才解除档位上限，之后仍按操作反馈逐级恢复。手动选定的档位不受失败计数影响。

极高性能保留连续重排；高性能在排序箭头实际变化后再决定下一次点击；中性能等待稳定画面，低性能多确认一帧。一次选人流程使用固定的档位，下一次选人才能使用新判定。

截图最短间隔、选人采样间隔、操作反馈超时、跑单前置延时和葛朗台缓冲时间都可以独立设置。切换性能档位或自动调档不会改写这些数值。旧 `custom` 配置按已保存的选人策略迁移到高或中性能，并保留时间参数；旧 `low_frame_rate_mode` 字段仍用于兼容未设置性能档位的配置。

选人排序、翻页和最终名单复核均读取新画面。蓝框检测在重排前确认已选卡片；中、低性能也执行蓝框检测。翻页时姓名区域未变化可以复用之前的姓名识别结果，但蓝框仍从新画面读取。

蓝框名单按卡片在页面上的位置排列，卡片上的选择编号则按点击顺序排列。多干员重排时按目标顺序重新点击；逐次反馈及最终复核只比较已选集合，不把页面顺序误认为选择编号顺序。

选人列表一旦翻页，返回首列统一切换职业筛选；无翻页的高性能路径仍直接复核。蓝框检测会区分相邻卡片边缘溢出的蓝色，避免把未选中卡片长期判为不确定。
