# 心情上下限

在排班页「心情上下限」中，可以为全体排班干员设置默认范围，也可以添加指定干员单独设置。主表、副表均支持，开启或关闭测试宿舍逻辑都生效。

## 生效范围与优先级

- 仅作用于**当前生效排班中的主班和替班**。未写入排班的干员保持原行为，即使已被读入心情缓存或出现在个人上下限配置中也不生效。
- 优先级：**指定干员设置 → 全体设置 → 原有自动规则**。上下限作为一对设置，范围为 `0 ≤ 下限 < 上限 ≤ 24`。
- 令夕模式保留：感知模式令为 0～12、夕为 12～24；烟火模式相反，相关工作组成员仍按原规则自动设置下限 12。均衡模式恢复原范围。铅踝的原有自动范围同样保留；手动设置可覆盖这些结果。
- 副表未设置的部分继承；多个副表对同一项都设置时，排在后面的生效副表覆盖。退出副表恢复之前的设置。个人设置始终优先于全体设置。
- 关闭全体自定义或移除个人条目，即恢复相应继承／自动规则。排班导入、导出、保存和一键替换干员会保留个人设置；旧排班无需修改。

## 调度行为

复用原令夕的 `lower_limit`、`upper_limit`、阈值和恢复计时，不另建调度算法。

| 判断 | 规则 |
| --- | --- |
| 普通下班阈值 | 下限＋（上限－下限）×排班心情阈值 |
| 急救线 | 下限＋（上限－下限）×排班心情阈值×全局急救阈值 |
| 下班先后 | 当前心情－个人下限，从低到高；仍检查替班、床位和整组条件 |
| 回满与恢复计时 | 使用个人上限，按实读恢复速度计算抵达上限的时间 |
| 耗尽预测 | 沿用原逻辑，以个人下限计算可用心情 |
| 到达上限 | 有手动设置者及令夕自动限制者到上限即离宿，不再入宿，不依赖“不养闲人”开关；固定宿管保留岗位 |
| 整组回班 | 先到上限者离宿等待；整组完成后仍生成回班安排，不因床位已清空而遗失回班 |
| 修改或切表 | 更新上下限，换算缓存倒计时，取消旧上限释放任务；无法可靠换算时重新读取 |

例：上下限为 8～20，休息阈值 50%，普通下班阈值为 **14**。全局急救阈值为 50% 时，急救线为 **11**。自定义范围保留小数精度，不再受原“距上限不足 2 心情不下班”的固定差值阻挡。

下限不代表立即强制下班，上限也不能保证网络或识别失败时零延迟执行。训练室、加工、用尽回满等原有保护继续生效；菲亚梅塔充能仍按原技能流程执行。
