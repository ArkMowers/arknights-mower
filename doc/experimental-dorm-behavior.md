# 测试宿舍逻辑行为对照

此页记录 PR #1110 及其修复完成后的运行语义，区分原有上下班规则、此前已有的实验功能和本 PR 的改动。这里的“测试逻辑”指设置 `experimental_dorm_logic`，不是单元测试。

## 上下班与床位排序分离

原来的下班候选计算是 `current_mood() - lower_limit` 升序，见引入分层排序之前的 `0e192598^`。例如心情 8、下限 12 的余量为 −4，应先于心情 1、下限 0 的干员尝试下班。

后来的 #942 把主班层级加入下班排序，#1039 又在实验模式中使用了宿舍层级及绝对心情。这次修复移除下班顺序中的两种层级干预，两种模式均恢复原公式；不改变配置里的宿舍优先名单。

| 环节 | 修复后行为 | 本次是否修改 |
| --- | --- | --- |
| 工作组下班候选顺序 | 只按当前心情减心情下限排序，不读取显式优先名单、高低优和候补层级 | 已恢复原逻辑，两种模式都生效 |
| 能否实际下班 | 继续检查阈值、用尽规则、替班可用性和整组床位需求；失败继续尝试后续候选 | 保留 |
| 普通空闲人员补床 | 工作组完成换班规划后再处理；实验模式补床内部使用宿舍层级和绝对心情 | 与下班候选分开，避免补床先占用主班所需床位 |
| 入住宿舍的先后和床位选择 | 已确定下班的组仍按宿舍优先级分床；名单可影响组内床位，不能让该组提前下班 | 保留 |
| 回班时间 | 仍使用床位恢复时间、组内回班、回满和用尽规则；非用尽回班提前量与原有急救时间规则保留 | 未改公式；状态输入及任务一致性见下表 |

## 实验逻辑的其他改动

“本 PR”以共同基线的三点差异为准，避免把主分支后续独立功能误列进来。

| 逻辑 | 当前实验模式行为 | 来源及关闭实验时的区别 |
| --- | --- | --- |
| 宿舍层级 | 显式名单 → 普通主班 → 低优主班 → 候补 → 普通替班 → 其他空闲；同级按有效绝对心情，未知心情靠后 | 层级主要继承 #1039；本次仅撤掉对下班候选顺序的影响。旧模式仍采用旧宿舍排序 |
| 常驻宿舍成员的 `Free` 替班 | 必须显式填写 `Free`，该成员随组离岗后才开放为动态床；填写具体姓名不再隐式开启动态床 | 本 PR 改动；实验模式专用 |
| 绑组宿舍的具体替班 | 按有效心情选替班，删除“同组姓名优先／同组主班作为固定恢复床”的特殊处理 | 本 PR 改动；不是额外下班优先级 |
| 候补适用范围 | 从仅绑组扩展到未绑组主班；未绑组者需已有高优恢复者提供待命依据 | 本 PR 改动；关闭后仍限绑组候补 |
| 候补急救 | 跌破由个人上下限、排班阈值和全局急救阈值换算的急救线后，本轮作为低优主班，必须有床；实际回班才解除 | 本 PR 新增；仅改变候补能否无床待命及分床资格 |
| 待命补床 | 符合待命条件者可参与不养闲人的补床；已有未来回班任务不妨碍先补床，也不因补床改写该回班时刻 | 本 PR 扩展 |
| 正常宿舍重排 | 落实本轮已选床位，保留正在恢复者的位置；不在每轮按变化后的心情重新搬动全宿舍 | 本 PR 修复；旧模式仍采用原全局重排 |
| 副表导致床位变化 | 仅床位集合、固定岗位或宿舍顺序等布局发生变化时迁移；无关副表切换不搬床 | 本 PR 修复；保留恢复计时和在宿舍继续恢复的机会 |
| 副表触发时机 | 实验模式每次检查在缓存内反复计算到条件稳定，不再按 BEFORE_WORK／BEFORE_DORM 等阶段逐次执行；循环或计算错误退回原状态 | 本 PR 的实质语义变化。关闭时走旧的分阶段副表流程 |
| 副表任务生成 | 自定义任务、改动岗位纠偏和必要宿舍迁移合并为最终差异；退出副表恢复它写过的槽位，不做全基地无差别纠错 | 本 PR 改动 |
| 换班任务组织 | 工作岗位替换和本轮宿舍安排合并进下班任务，避免两者之间出现“离岗但未入宿舍”的中间状态 | 本 PR 修复；部分公共路径也受益 |
| 回班状态推演 | 在副本中投影已确定的纠错／重排，再生成后续回班和释放；计时跟随入住者，相关回班晚于迁移，无关回班不延迟 | 本 PR 修复；不提前改真实床位 |
| 同刻回班与释放 | 两种任务分别保留类型；跳过已经失效的床位记录，修复同时间批次和无在岗者时的时间溢出 | 本 PR 修复，包含公共调度路径 |
| 确认进驻后的恢复 | 确认按钮已提交但读取失败时，重新观察实际阵容，并补读恢复计时；实验纠错／重排完成后重建派生回班 | 本 PR 修复，包含公共进驻恢复路径 |
| 跑单资格 | 只为当前实际／目标产物允许且配置了跑单替班的贸易站生成跑单；卖玉房间不参与，并清理无效任务 | 本 PR 改动；关闭后保留旧判断 |
| 跑单与空宿舍 | 动态空床不再阻止读取跑单时间；旧模式“宿舍必须满员”的前置条件保留 | 本 PR 改动，实验专用 |
| 跑单延期与补床 | 跑单保护延期后可补一次空余宿舍；纯宿舍任务批次不因跑单而整体延期；合并延期宿舍安排时保留一次最终入住及必要计时 | 本 PR 改动，实验专用 |
| 副表切换后的规划唤醒 | 重建已有回班队列后仍补普通规划唤醒，避免 RE_ORDER 的 skip 让跑单长期缺失 | 此前修复 197924c7；恢复原流程意图，不改 15 分钟刷新规则 |
| 副表与制造产物切换 | 换人前投影产物需求，优先完成产物切换；不能完成时仅延期相关岗位，其他独立安排继续 | 本 PR 实质变化；关闭时走旧切产物流程 |
| 制造进度和无人机 | 根据当前份剩余进度、加速效率、损耗及无人机上限决定加速、等待或按配置直接切换；避免长期阻塞当前任务 | 本 PR 新增／扩展；设置说明与实验模式联动 |
| 延期切产物资源 | 保留任务、重试时刻及相关人员／床位预留，普通回班重建和其他换班不能抢占这些资源 | 本 PR 新增，实验专用；并不等于所有普通跑单延期任务均已具备相同预留 |

## 保留的规则与边界

- 整组替班齐备、用尽下班、回满、菲亚梅塔、训练室专精保护仍由原有规则处理；本次没有新设一套“红脸组”特殊任务。
- `refresh_run_order_time()` 的 15 分钟删除／强制刷新分支保留。不能把远端未部署唤醒修复时的跑单缺失归因为本次心情排序修复。
- 宿舍房间顺序配置迁移、普通替班身份判定及主力恢复中的入住保护等，已有部分在 PR 基线中存在；不能把所有实验与旧模式的区别都算作本 PR 新增。
- 未修改远端配置、未重启或部署。alex 的状态回放验证证明此次排序修复能让感知组获得替班并生成下班安排，不代表所有组合已在线验证。
- 日志另确认普通跑单延期任务沿用旧床位、覆盖机械师用尽回满床位的问题；它独立于本次排序修复，尚未修复，也尚未完成引入版本的判定。
